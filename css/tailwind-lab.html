Tailwind Learning Lab

⚡ The CSS-to-Tailwind Translator

You did not waste a single second learning raw CSS. Tailwind is literally just raw CSS written as short class names. Look at this side-by-side guide to see how your CSS knowledge translates instantly!

1. Sizing & Box Model

// Raw CSS you learned

.card {
    width: 320px;
    height: 160px;
    padding: 24px;
    margin: 20px auto;
    border: 2px solid #ffffff;
    border-radius: 12px;
}

// Tailwind Utility Shorthand

<div class="
    w-[320px] 
    h-[160px] 
    p-6 
    my-5 mx-auto 
    border-2 border-white 
    rounded-xl
"></div>

2. Flexbox Alignments

// Raw CSS you learned

.header-bar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 16px;
    flex-wrap: wrap;
}

// Tailwind Utility Shorthand

<div class="
    flex 
    justify-between 
    items-center 
    gap-4 
    flex-wrap
"></div>
