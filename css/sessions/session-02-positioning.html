The code is surprisingly simple
.sticky-header {
  position: sticky;
  top: 0;  /* stick at 0px from top */
  background: #10b981;
  z-index: 10;
}

6 z-index — Who's On Top?

📋 Quick Cheat Sheet

static
Default. Normal flow.
top/left = IGNORED
relative
Normal flow + nudgeable.
Anchor for absolute kids
absolute
Removed from flow.
Relative to ancestor
fixed
Fixed to viewport.
Stays on scroll
sticky
Hybrid: relative → fixed.
Sticks on scroll
The Positioning Mental Model: position: static → "I go where the flow puts me" position: relative → "I stay in flow, but I can nudge myself" position: absolute → "I break free! I answer to my positioned parent" position: fixed → "I'm glued to the screen. I don't care about scrolling" position: sticky → "I act normal until I hit a scroll point, then I stick" z-index → "When we overlap, the bigger number wins" (only works on positioned elements!)
