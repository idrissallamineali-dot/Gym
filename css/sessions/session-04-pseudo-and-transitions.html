🏆 Clone Challenge: Interactive Navigation Bar

Recreate this navbar with hover effects, transitions, ::after underlines, and :first-child active state.

Hover the links and button in the target below!

GameHub
  • Home
  • Browse
  • Library
  • Community
  • Support

Requirements:

  • Gradient background on the nav
  • Links change color + slight background on :hover (with transition)
  • ::after underline grows from center on hover
  • :first-child link has "active" state (green color, visible underline)
  • CTA button lifts on hover with shadow
HTML STRUCTURE
<nav class="navbar">
  <div class="nav-logo">GameHub</div>
  <ul class="nav-links">
    <li><a href="#">Home</a></li>
    <li><a href="#">Browse</a></li>
    <li><a href="#">Library</a></li>
    <li><a href="#">Community</a></li>
    <li><a href="#">Support</a></li>
  </ul>
  <button class="nav-cta">Sign Up</button>
</nav>
HINTS
  • Nav layout: Use display: flex; align-items: center; justify-content: space-between
  • Gradient: background: linear-gradient(135deg, #1a1a2e, #16213e)
  • Links list: display: flex; list-style: none; gap: 4px
  • Link hover: Add transition: color 0.3s, background-color 0.3s
  • ::after underline: Link needs position: relative. The ::after needs position: absolute; bottom: 2px; width: 0. On hover, set width: 60%
  • Center the underline: left: 50% by default, then left: 20% on hover (to center a 60% width line)
  • Active state: li:first-child a { color: #10b981 } and give its ::after a visible width
  • CTA button: transition: transform 0.2s, box-shadow 0.2s
FULL CSS SOLUTION
.navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 16px 32px;
  background: linear-gradient(135deg, #1a1a2e, #16213e);
  border-radius: 12px;
}

.nav-logo {
  font-size: 20px;
  font-weight: 900;
  color: #fff;
}

.nav-links {
  display: flex;
  gap: 4px;
  list-style: none;
}

.nav-links a {
  color: #a0aec0;
  text-decoration: none;
  font-size: 14px;
  font-weight: 500;
  padding: 8px 16px;
  border-radius: 6px;
  position: relative;
  transition: color 0.3s ease, background-color 0.3s ease;
}

/* ::after underline (hidden by default) */
.nav-links a::after {
  content: '';
  position: absolute;
  bottom: 2px;
  left: 50%;
  width: 0;
  height: 2px;
  background: #10b981;
  border-radius: 1px;
  transition: width 0.3s ease, left 0.3s ease;
}

/* Hover state */
.nav-links a:hover {
  color: #fff;
  background: rgba(255, 255, 255, 0.05);
}
.nav-links a:hover::after {
  width: 60%;
  left: 20%;
}

/* Active state — first child */
.nav-links li:first-child a {
  color: #10b981;
}
.nav-links li:first-child a::after {
  width: 60%;
  left: 20%;
  background: #10b981;
}

/* CTA Button */
.nav-cta {
  padding: 10px 22px;
  background: #10b981;
  color: #fff;
  border: none;
  border-radius: 8px;
  font-size: 14px;
  font-weight: 700;
  cursor: pointer;
  transition: transform 0.2s ease, box-shadow 0.2s ease;
  box-shadow: 0 2px 8px rgba(16, 185, 129, 0.2);
}
.nav-cta:hover {
  transform: translateY(-2px);
  box-shadow: 0 8px 24px rgba(16, 185, 129, 0.3);
}
