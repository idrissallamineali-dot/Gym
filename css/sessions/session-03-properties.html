🎯 Clone Challenge: Style This Hero Section

Recreate the LUGX hero section's left column text using the CSS properties you learned in this session. Match the target below as closely as possible.

Welcome to LUGX

THE BEST GAMING

EXPERIENCE

LUGX Gaming is a free platform where you can buy and play the best games. Join millions of gamers worldwide and discover your next favorite game.

Explore Now

Your starter HTML:

<div class="hero">
  <p class="hero-subtitle">Welcome to LUGX</p>
  <h2 class="hero-heading">
    THE BEST <span class="highlight">GAMING</span>
  </h2>
  <h2 class="hero-heading">EXPERIENCE</h2>
  <p class="hero-text">
    LUGX Gaming is a free platform where you can buy and play
    the best games. Join millions of gamers worldwide and
    discover your next favorite game.
  </p>
  <a href="#" class="hero-btn">Explore Now</a>
</div>
HINTS
  • .hero needs background: linear-gradient() with dark blues and padding
  • .hero-subtitle uses text-transform: uppercase, letter-spacing: 2px, small font-size
  • .hero-heading uses font-size: 48px, font-weight: 800, text-transform, tight letter-spacing
  • .highlight needs border-bottom: 4px solid #e74c3c and some padding-bottom
  • .hero-text uses a lighter color via rgba() and line-height: 1.8
  • .hero-btn needs display: inline-block, border-radius: 50px, and text-decoration: none
SOLUTION
/* ===== Hero Container ===== */
.hero {
  background: linear-gradient(135deg, #0a1628 0%, #162447 50%, #1f4068 100%);
  border-radius: 12px;
  padding: 48px 40px;
}

/* ===== Subtitle ===== */
.hero-subtitle {
  font-size: 12px;
  font-weight: 700;
  text-transform: uppercase;
  letter-spacing: 2px;
  color: rgba(255, 255, 255, 0.5);
  margin-bottom: 12px;
}

/* ===== Heading ===== */
.hero-heading {
  font-size: 48px;
  font-weight: 800;
  text-transform: uppercase;
  letter-spacing: -1px;
  color: #fff;
  line-height: 1.1;
  margin-bottom: 8px;
}

.hero-heading:last-of-type {
  margin-bottom: 24px;
}

/* ===== GAMING highlight ===== */
.highlight {
  border-bottom: 4px solid #e74c3c;
  padding-bottom: 4px;
}

/* ===== Body text ===== */
.hero-text {
  font-size: 15px;
  color: rgba(255, 255, 255, 0.55);
  line-height: 1.8;
  max-width: 480px;
  margin-bottom: 32px;
}

/* ===== Button ===== */
.hero-btn {
  display: inline-block;
  padding: 14px 32px;
  background: #e74c3c;
  color: #fff;
  border-radius: 50px;
  font-size: 14px;
  font-weight: 700;
  text-transform: uppercase;
  letter-spacing: 1px;
  text-decoration: none;
  cursor: pointer;
}
