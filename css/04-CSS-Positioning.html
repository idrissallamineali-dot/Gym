0 What is Positioning? (The Mental Model)

Before we dive into code, let's understand why positioning exists. In Tutorial 2, you learned about normal flow: block elements stack vertically, inline elements sit side by side. That's great for 90% of your layout.

But what about a price badge that sits ON TOP of a game card image? Or a navbar that stays at the top even when you scroll? Normal flow can't do that. That's where CSS positioning comes in.

The 4 Main Position Values

Every element in CSS has a position property. Here are the values you'll use:

  • static — The default. Element follows normal flow. Can't be nudged.
  • relative — Element stays in normal flow but CAN be nudged from its original spot.
  • absolute — Element is REMOVED from flow. Positions itself relative to its nearest positioned ancestor.
  • fixed — Element is REMOVED from flow. Positions itself relative to the browser window (viewport).

The Big Picture (ASCII Diagram)

NORMAL FLOW (static / relative) TAKEN OUT OF FLOW (absolute / fixed) ┌──────────────────────────────┐ ┌──────────────────────────────┐ │ ┌──────────────────────────┐ │ │ ┌──────────────────────────┐ │ │ │ Header (block) │ │ │ │ Header │ │ │ └──────────────────────────┘ │ │ └──────────────────────────┘ │ │ ┌──────────────────────────┐ │ │ │ │ │ Nav (block) │ │ │ ← Gap! Element removed │ │ └──────────────────────────┘ │ │ │ │ ┌──────────────────────────┐ │ │ ┌──────────────────────────┐ │ │ │ Main (block) │ │ │ │ Main │ │ │ └──────────────────────────┘ │ │ └──────────────────────────┘ │ └──────────────────────────────┘ └──────────────────────────────┘ Elements stack one after another. ┌─────────┐ Each takes up its full space. Nav floats free │ Nav │ somewhere else └─────────┘
🧠 Key Mental Model: Think of normal flow like a stack of books on a table. static and relative keep the book in the stack. absolute and fixed lift the book off the table entirely — the other books close the gap as if it was never there.

The Positioning Controls

Once an element is positioned (anything other than static), you unlock 4 offset properties:

  • top — push it down from the top edge
  • right — push it left from the right edge
  • bottom — push it up from the bottom edge
  • left — push it right from the left edge
top ↓ ┌──────────────────┐ left →│ │← right │ ELEMENT │ │ │ └──────────────────┘ ↑ bottom

1 position: static (The Default)

Every single element starts with position: static. You never have to write it — it's the browser default. A static element:

  • Follows normal flow (block elements stack, inline elements sit side by side)
  • Ignores top, right, bottom, left — they do absolutely nothing
  • Ignores z-index

Demo: top/left Do NOTHING on Static

Watch this — we set top: 50px and left: 100px on a static element, and it doesn't move at all:

.static-box {
    position: static;       /* default — you don't even need to write this */
    top: 50px;               /* ❌ IGNORED! */
    left: 100px;             /* ❌ IGNORED! */
    background: #1e2d4a;
    padding: 20px;
}
▶ Live Result
I have top:50px and left:100px but I haven't moved! 🤷
❌ Common Mistake: Beginners add top or left and wonder why nothing moves. The answer is almost always: you forgot to add position: relative (or absolute). Static elements ignore offset properties entirely.

2 position: relative

position: relative does two important things:

  1. Lets you nudge the element from its original position using top, right, bottom, left.
  2. Makes the element an anchor for any position: absolute children inside it. (This is its REAL superpower — more on that in Section 3.)
🧠 Key Concept: A relative element does NOT leave normal flow. The space it originally occupied is preserved. Other elements act as if it's still in its original spot — even if you nudge it 200px away.

Demo: Nudging a Box with top/left

.relative-box {
    position: relative;
    top: 20px;        /* push DOWN 20px from original spot */
    left: 40px;       /* push RIGHT 40px from original spot */
}

💡 Pro Tip: In practice, you'll rarely use relative to visually nudge things. Its #1 use is as an anchor parent for absolute children. That's the real reason you'll write position: relative — we'll see this in the very next section.

3 position: absolute (THE KEY CONCEPT)

This is the most important positioning value and the one you'll use most on the LUGX Gaming site. Here's what absolute does:

  1. Removes the element from normal flow — other elements act as if it doesn't exist.
  2. Positions itself relative to its nearest positioned ancestor (an ancestor with position: relative, absolute, or fixed).
  3. If there's NO positioned ancestor, it positions relative to the <body> (the whole page).

The Parent-Child Rule

This is the golden rule you must memorize:

✅ The Rule: To position a child inside a parent, set the parent to position: relative and the child to position: absolute. The child will then use the parent's edges as its coordinate system. 
/* THE PARENT — becomes the anchor */
.card {
    position: relative;    /* ← This is the anchor */
    width: 300px;
    height: 200px;
}

/* THE CHILD — positions itself inside the parent */
.badge {
    position: absolute;   /* ← Taken out of flow */
    top: 10px;             /* 10px from the TOP of .card */
    right: 10px;           /* 10px from the RIGHT of .card */
}
Parent (position: relative) ┌─────────────────────────────────────┐ │ ┌─────────┐ │ │ │ $22 │ │ ← top: 10px, right: 10px │ │ (badge) │ │ │ └─────────┘ │ │ │ │ Game Card Image │ │ │ │ │ └─────────────────────────────────────┘

Demo: The LUGX Price Badge on a Card

4 position: fixed

position: fixed is similar to absolute, but instead of positioning relative to a parent element, it positions relative to the viewport (browser window). It does not move when you scroll.

  • Removed from normal flow (like absolute)
  • Positions relative to the browser window, not any parent
  • Stays in place when the user scrolls the page

Common Use Cases

  • Sticky navbars — the top navigation bar that follows you as you scroll
  • "Back to top" buttons — a small button fixed to the bottom-right corner
  • Cookie banners — the bar at the bottom asking you to accept cookies
  • Chat widgets — the floating chat bubble on many websites
.back-to-top {
    position: fixed;       /* Fixed to the viewport */
    bottom: 20px;           /* 20px from the bottom of the window */
    right: 20px;            /* 20px from the right of the window */
    background: #0071F8;
    color: white;
    width: 48px;
    height: 48px;
    border-radius: 50%;
    display: flex;
    align-items: center;
    justify-content: center;
    font-size: 20px;
    cursor: pointer;
    z-index: 999;           /* Ensure it's on top of everything */
}

💡 Pro Tip: If you use position: fixed on a navbar, the content below it will slide under it (because the navbar is removed from flow). Fix this by adding padding-top to the body equal to the navbar height. For example, if your navbar is 70px tall: body { padding-top: 70px; }
❌ Warning: Fixed elements are removed from normal flow, just like absolute. This means they can cover other content. Always use z-index to control layering and test on mobile devices where screen space is limited!

5 position: sticky (Bonus)

position: sticky is a hybrid — it acts like relative until the user scrolls past a threshold, then it "sticks" like fixed. It's the modern way to create sticky headers, sidebars, and section labels.

How It Works

  1. The element sits in normal flow (like relative).
  2. When you scroll, and the element reaches the top value you set, it sticks to that position.
  3. It stays stuck until its parent element scrolls out of view.
.sticky-header {
    position: sticky;
    top: 0;               /* Stick to the top when scrolled */
    background: #0f111a;
    padding: 16px;
    z-index: 10;
}

6 z-index — Stacking Order

When you position elements on top of each other (using absolute, fixed, etc.), which one is on top? That's what z-index controls.

The Rules of z-index

  • Higher z-index = on top. An element with z-index: 10 is above z-index: 5.
  • Default is auto (effectively 0).
  • Only works on positioned elements — z-index does nothing on position: static.
  • Can be negative — z-index: -1 pushes elements behind the normal flow.
Side view (imagine looking at the screen from the side): Screen ────────────── │ z-index: 30 │ ← front (user sees this) │ z-index: 20 │ │ z-index: 10 │ │ z-index: 1 │ │ (static) │ ← back ────────────── ← user's eyes here
.box-red    { position: relative; z-index: 1; }
.box-green  { position: relative; z-index: 2; }  /* on top of red */
.box-blue   { position: relative; z-index: 3; }  /* on top of both */

💡 Pro Tip: Don't use huge numbers like z-index: 99999. Use a sensible scale: 1-10 for regular positioned elements, 100 for dropdowns, 1000 for modals, 9999 for overlays/tooltips. This keeps things manageable.
🧠 Why doesn't my z-index work? Two common reasons:
1. The element has position: static (z-index only works on positioned elements).
2. Stacking context — a parent with a lower z-index creates a ceiling for its children. Even if a child has z-index: 9999, it can't escape its parent's stacking context. (This is an advanced topic — for now, just know it exists.)

7 CSS Gradients & Backgrounds

The LUGX Gaming site uses beautiful gradient backgrounds — those smooth color transitions that go from dark blue to a lighter blue. Let's learn how to create them.

background-color vs background

First, know the difference:

  • background-color — sets a single, solid color. Example: background-color: #0071F8;
  • background — the shorthand that can set color, image, gradient, and more all at once. Example: background: linear-gradient(...);
ℹ️ Note: Gradients are technically background images, not colors. That's why you must use background (not background-color) for gradients.

linear-gradient — The Most Common

A linear gradient creates a smooth transition between two or more colors along a straight line.

/* Basic syntax */
background: linear-gradient(direction, color1, color2);

/* Examples */
background: linear-gradient(to right, #0071F8, #00c6ff);     /* left to right */
background: linear-gradient(to bottom, #0071F8, #003d8f);    /* top to bottom */
background: linear-gradient(135deg, #667eea, #764ba2);      /* diagonal */

Direction Options

  • to right — left → right (same as 90deg)
  • to bottom — top → bottom (same as 180deg, this is the default)
  • to bottom right — diagonal, top-left → bottom-right
  • 45deg, 135deg, 270deg — any angle you want
Direction Reference: 0deg (to top) ↑ │ 270deg ←──────────┼──────────→ 90deg (to right) (to left) │ ↓ 180deg (to bottom, DEFAULT)

Multi-Stop Gradients

You can add color stops — specific points where each color is at its most intense. This gives you finer control:

/* The LUGX-style blue gradient */
background: linear-gradient(180deg, #0071F8 0%, #0056c6 50%, #003d8f 100%);

/* Read it as: */
/*   At 0% (top)    → bright blue  #0071F8  */
/*   At 50% (middle) → medium blue #0056c6  */
/*   At 100% (bottom) → dark blue  #003d8f  */
▶ Live Result — LUGX Blue Gradient
LUGX Gaming Gradient

radial-gradient — Glow & Spotlight Effects

A radial gradient radiates outward from a center point — perfect for glow or spotlight effects.

/* Basic radial gradient */
background: radial-gradient(circle, #0071F8, #0f111a);

/* Glow effect behind a card */
background: radial-gradient(circle at center, rgba(0,113,248,0.3) 0%, transparent 70%);
▶ Live Result — Radial Gradient Glow
🎮 Game Card with Glow
💡 Pro Tip: You can combine multiple backgrounds using commas. The LUGX site likely uses something like: background: radial-gradient(... glow ...), linear-gradient(... base ...); — the first background is drawn on top.

Gradient Overlay on an Image

A popular pattern: place a gradient on top of an image to make text readable. In the LUGX site, the bottom of game cards has a dark gradient fade so the game title is readable:

.card-image {
    position: relative;
}

.card-image::after {
    content: "";
    position: absolute;
    bottom: 0; left: 0; right: 0;
    height: 50%;
    background: linear-gradient(to top, rgba(0,0,0,0.8), transparent);
}

✅ position: static — Default. Normal flow. Can't use top/right/bottom/left.
✅ position: relative — Stays in flow. Can nudge. Becomes anchor for absolute children.
✅ position: absolute — Removed from flow. Positions relative to nearest positioned ancestor.
✅ position: fixed — Removed from flow. Positions relative to viewport. Doesn't scroll.

✅ linear-gradient — Smooth color transition along a line.
✅ radial-gradient — Smooth color transition from center outward.
✅ The Golden Rule — Parent: relative, Child: absolute.
