1.1 The Flexbox Mental Model

What is Flexbox?

Flexbox (Flexible Box Layout) is a one-dimensional layout system. It distributes space among items in a container along a single axis — either a row (horizontal) or a column (vertical). It handles alignment, spacing, sizing, and ordering of child elements automatically.

🧠 The Two Axes Mental Model
Flexbox always operates on two axes:
1. Main Axis: The primary direction items flow. (Default: horizontal, left → right).
2. Cross Axis: The perpendicular direction. (Default: vertical, top → bottom).

Every Flexbox property controls either the Main Axis or the Cross Axis. If you understand which axis a property targets, you will never be confused.
🏗️ Two Types of Flexbox Properties
1. Container Properties: Set on the parent element (display: flex). These control how children are laid out.
2. Item Properties: Set on individual children. These let specific items override the container's default behavior.

1.2 Container Properties (The Parent)

display: flex — Activating Flexbox

This single declaration transforms a normal block container into a flex container. All direct children become flex items and are immediately laid out side-by-side in a row (the default main axis direction).

The Holy Grail: Perfect Centering

The most famous Flexbox trick. To center anything both horizontally and vertically in a container, you only need 3 lines:

Live Demo — Perfect Centering

Centered!
display: flex; justify-content: center; align-items: center;
.parent {
    display: flex;
    justify-content: center;  /* Center on main axis (horizontal) */
    align-items: center;      /* Center on cross axis (vertical) */
    height: 100vh;             /* Full viewport height */
}

gap — Adding Space Between Items

The gap property adds consistent spacing between flex items without affecting the outer edges. It replaces the old margin-based spacing hacks. You can set row-gap and column-gap independently, or use the shorthand gap.

gap: 20px

1
2
3
4
gap: 20px; /* 20px between all items, NO gap on the outer edges */
.container {
    display: flex;
    gap: 20px;               /* Shorthand: same gap for rows and columns */
    gap: 20px 40px;          /* Shorthand: row-gap 20px, column-gap 40px */
    row-gap: 20px;           /* Separate: only the gap between rows */
    column-gap: 40px;        /* Separate: only the gap between columns */
}

1.3 Item Properties (The Children)

flex-grow — How Items Expand

This property controls how much a flex item grows relative to siblings when there is leftover space in the container. The default value is 0 (don't grow). A value of 1 means "take an equal share of remaining space." A value of 2 means "take twice the share."

All items flex-grow: 1 (equal growth)

flex-shrink — How Items Contract

When items overflow their container, flex-shrink controls how much each item shrinks relative to siblings. The default is 1 (shrink equally). A value of 0 means "never shrink — maintain my size."

flex-basis — The Starting Size

flex-basis sets the ideal starting size of a flex item before any growing or shrinking happens. Think of it as "the size the item wants to be." It overrides width (in row direction) or height (in column direction).

flex — The Shorthand (grow, shrink, basis)

The flex shorthand combines flex-grow, flex-shrink, and flex-basis in one declaration. This is the recommended way to set flex item sizing.

align-self — Individual Cross-Axis Override

While align-items is set on the container and affects all items, align-self is set on a single item and overrides the container's cross-axis alignment for that item only.

Container: align-items: flex-start — Item 2: align-self: flex-end

1 (start)
2 (self: end)
3 (start)
4 (self: center)
Item 2: align-self: flex-end; Item 4: align-self: center;

order — Rearranging Items Visually

By default, flex items appear in their HTML source order. The order property lets you reorder them visually without changing the HTML. Lower values appear first. Default is 0.

HTML order: 1-2-3 — Visual order: 3-1-2

1 (order:2)
2 (order:3)
3 (order:1)
/* Visual order is: Item 3 → Item 1 → Item 2 */
