1 Text & Font Properties

These properties control how text looks — its color, size, weight, spacing, and decoration. You'll use these on every single project.

1. color

What it does: Sets the color of the text inside an element.

/* Named colors */
color: red;
color: tomato;
color: white;

/* Hex (most common) — # followed by 6 hex digits */
color: #ff0000;          /* red */
color: #10b981;          /* green */
color: #f0f6fc;          /* near-white */

/* RGB — red, green, blue (0-255 each) */
color: rgb(255, 0, 0);   /* red */

/* RGBA — RGB + alpha (transparency: 0=invisible, 1=solid) */
color: rgba(255, 0, 0, 0.5);  /* 50% transparent red */
▶ Live Result

This text uses color: #f85149 (red)

This text uses color: #10b981 (green)

This text uses color: #7dd3fc (blue)

This text uses color: rgba(255,255,255,0.4) (40% white)

✅ When to use it: Every element with text. Headings get bright colors (#f0f6fc), body text gets muted colors (#b0bac9), and links or accents get your brand color (#10b981).

2. font-family

What it does: Chooses which font to display text in. You provide a fallback stack — the browser tries the first font, and if it's not available, tries the next one.

/* Fallback stack — browser tries left to right */
font-family: 'Inter', sans-serif;

/* Common stacks: */
font-family: 'Helvetica Neue', Arial, sans-serif;  /* Clean modern */
font-family: 'Georgia', serif;                       /* Classic book feel */
font-family: 'JetBrains Mono', monospace;              /* Code/terminal */
▶ Live Result

This is Inter (sans-serif) — clean and modern

This is Georgia (serif) — classic and elegant

This is JetBrains Mono (monospace) — for code

This is Times New Roman — traditional newspaper feel

🧠 Why fallback stacks? Not every computer has the same fonts installed. The last value should always be a generic family: sans-serif, serif, or monospace. This guarantees the browser always has something to use.

3. font-size

What it does: Controls how big the text is.

font-size: 16px;    /* Pixels — fixed size, most common for beginners */
font-size: 1rem;    /* Relative to root font size (usually 16px) */
font-size: 1.2em;   /* Relative to parent's font size */
▶ Live Result

font-size: 12px — Small caption text

font-size: 16px — Default body text

font-size: 20px — Slightly larger

font-size: 28px — Subheading

font-size: 40px — Hero title

💡 Pro tip: Use px while learning. Once comfortable, switch to rem for better scalability. 1rem = 16px by default. So 1.5rem = 24px, 2rem = 32px.

4. font-weight

What it does: Controls how bold (thick) the text is. Uses numeric values from 100 to 900.

font-weight: 100;   /* Thin */
font-weight: 300;   /* Light */
font-weight: 400;   /* Normal (default) — same as font-weight: normal */
font-weight: 600;   /* Semi-bold */
font-weight: 700;   /* Bold — same as font-weight: bold */
font-weight: 900;   /* Black (extra bold) */
▶ Live Result

font-weight: 100 — Thin

font-weight: 300 — Light

font-weight: 400 — Normal

font-weight: 600 — Semi-bold

font-weight: 700 — Bold

font-weight: 800 — Extra-bold

5. font-style

What it does: Makes text italic or normal.

font-style: normal;    /* Default upright text */
font-style: italic;    /* Tilted/cursive version */
font-style: oblique;   /* Like italic but mechanically slanted */
▶ Live Result

font-style: normal — Regular upright text

font-style: italic — Italic text for emphasis or quotes

font-style: oblique — Mechanically slanted text

✅ When to use it: Use italic for quotes, citations, or emphasized words. Use font-style: normal to un-italicize something that's italic by default (like <em> or <address>).

6. line-height

What it does: Controls the vertical space between lines of text. Think of it as the "breathing room" between lines.

line-height: 1;      /* No extra space — lines touching */
line-height: 1.5;    /* 1.5x the font size — comfortable reading */
line-height: 1.8;    /* 1.8x — spacious, great for body text */
line-height: 2;      /* Double-spaced */
▶ Live Result

❌ line-height: 1

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.

✅ line-height: 1.8

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.

💡 Best practice: Use 1.5 to 1.8 for body text. Headings can use tighter values like 1.2. Never use 1 for paragraphs — it's unreadable.

7. letter-spacing

What it does: Adds or removes space between individual letters.

letter-spacing: 0;       /* Default */
letter-spacing: 2px;     /* Spread out — great for labels/nav */
letter-spacing: -1px;    /* Tighten — great for large headings */
▶ Live Result

letter-spacing: -1.5px (tight heading)

letter-spacing: 0px (default body text)

letter-spacing: 3px (spread label)

✅ When to use it: Negative values for big headings (tightens them up nicely). Positive values for small labels, nav items, or "UPPERCASE" text — they need extra spacing to be readable.

8. word-spacing

What it does: Adds or removes space between words (not letters).

word-spacing: 0;       /* Default */
word-spacing: 4px;     /* Words spread apart */
word-spacing: -2px;    /* Words closer together */
▶ Live Result

word-spacing: 0px — This is the default spacing between words.

word-spacing: 8px — Notice how the words are spread far apart.

word-spacing: -3px — Words are compressed closer together.

🧠 Rarely used. You'll almost never need word-spacing. It's here so you know it exists. letter-spacing is far more common.

9. text-align

What it does: Controls horizontal alignment of text inside its container.

text-align: left;      /* Default — text starts from the left */
text-align: center;    /* Centered in the container */
text-align: right;     /* Aligned to the right */
text-align: justify;   /* Stretches text to fill the full width */
▶ Live Result

text-align: left — This is the default alignment

text-align: center — Centered text

text-align: right — Right-aligned text

text-align: justify — This text is justified, meaning it stretches to fill the full width of the container on both sides, adding extra space between words as needed.

10. text-decoration

What it does: Adds or removes lines on text — underlines, overlines, and strikethroughs.

text-decoration: none;           /* Remove all lines (use on links!) */
text-decoration: underline;      /* Underline */
text-decoration: overline;       /* Line above text */
text-decoration: line-through;   /* Strikethrough */

/* Advanced sub-properties: */
text-decoration-color: #10b981;   /* Color of the line */
text-decoration-thickness: 3px;   /* Thickness of the line */
text-decoration-style: wavy;     /* solid, dashed, dotted, wavy, double */
▶ Live Result

text-decoration: none — No line

text-decoration: underline — Standard underline

text-decoration: overline — Line above

text-decoration: line-through — Strikethrough

Underline with color: #10b981 and thickness: 3px

Wavy underline in red (like a spell-check error!)

Dashed underline in blue

✅ When to use it: Use text-decoration: none on styled links to remove the ugly default underline. Use line-through for sale prices or completed tasks.

11. text-transform

What it does: Changes the capitalization of text without changing the HTML.

text-transform: uppercase;    /* ALL CAPS */
text-transform: lowercase;    /* all lowercase */
text-transform: capitalize;   /* First Letter Of Each Word */
text-transform: none;         /* Default — keep as written */
▶ Live Result

12. text-indent

What it does: Indents the first line of a paragraph, like in a book.

text-indent: 40px;   /* Indent first line by 40px */
text-indent: 2em;    /* Indent by 2x the font size */
▶ Live Result

text-indent: 40px — Notice how only the first line of this paragraph is indented, just like in a printed book. The second line wraps back to the normal left edge of the container.

13. white-space

What it does: Controls how whitespace and line breaks are handled inside an element.

white-space: normal;   /* Default — wraps text, collapses spaces */
white-space: nowrap;   /* Prevents text from wrapping to next line */
white-space: pre;      /* Preserves spaces and line breaks (like <pre>) */
▶ Live Result

white-space: normal (wraps)

This is a long sentence that will wrap to the next line when it reaches the edge of the container.

white-space: nowrap (overflows!)

This is a long sentence that will NOT wrap. It just keeps going and overflows the container.

14. text-overflow: ellipsis

What it does: Shows "..." when text is too long to fit in its container. But it needs 3 properties together to work:

.truncate {
  white-space: nowrap;           /* 1. Prevent wrapping */
  overflow: hidden;              /* 2. Hide the overflow */
  text-overflow: ellipsis;       /* 3. Show "..." at the cut point */
}
❌ Common mistake: Using text-overflow: ellipsis alone does nothing. You MUST also set overflow: hidden and white-space: nowrap. All three are required.
▶ Live Result

✅ With text-overflow: ellipsis:

This is a very long game title that should be truncated with beautiful ellipsis dots

✅ When to use it: Card titles, navbar items, table cells — anywhere text might overflow. Very common in game/product cards!

15. text-shadow

What it does: Adds a shadow behind text for depth or glow effects.

2 Background Properties

Background properties control what appears behind the content of an element — solid colors, images, or gradients.

1. background-color

What it does: Fills the element's background with a solid color.

background-color: #1a2035;            /* Dark blue */
background-color: rgba(0,0,0,0.5);    /* 50% transparent black */
background-color: transparent;        /* See through (default) */

2. background-image: url(...)

What it does: Uses an image file as the element's background.

background-image: url('hero-bg.jpg');
background-image: url('https://example.com/image.png');
ℹ️ When to use it: Hero sections, card banners, full-page backgrounds. The image sits behind any text/content inside the element.

3. background-image: linear-gradient(...)

What it does: Creates a smooth color transition as the background — no image file needed.

/* Top to bottom (default) */
background-image: linear-gradient(#0071F8, #10b981);

/* With direction */
background-image: linear-gradient(to right, #0071F8, #10b981);
background-image: linear-gradient(135deg, #0071F8, #10b981);

/* Three or more colors */
background-image: linear-gradient(90deg, #f85149, #e3b341, #10b981);

4. background-size

What it does: Controls how a background image is sized inside its container.

background-size: auto;      /* Original size (default) */
background-size: cover;     /* Fill container, may crop */
background-size: contain;   /* Fit inside, may leave space */
background-size: 100% 100%; /* Stretch to fill (may distort) */
✅ When to use it: Almost always use cover for hero images — it fills the container completely and looks professional. Use contain when you need to see the entire image without cropping.

5. background-position

What it does: Controls where the background image is positioned within the element.

background-position: center;        /* Dead center (most common) */
background-position: top left;      /* Top-left corner */
background-position: bottom right;  /* Bottom-right corner */
background-position: 50% 30%;       /* 50% from left, 30% from top */

6. background-repeat

What it does: Controls whether a background image tiles/repeats.

background-repeat: repeat;     /* Tiles in both directions (default) */
background-repeat: no-repeat;  /* Shows image once — USE THIS for photos */
background-repeat: repeat-x;   /* Tiles only horizontally */
background-repeat: repeat-y;   /* Tiles only vertically */

7. background-attachment

What it does: Controls whether the background scrolls with the content or stays fixed.

background-attachment: scroll;  /* Scrolls with content (default) */
background-attachment: fixed;   /* Stays in place — parallax effect! */

8. background (Shorthand)

What it does: Combines all background properties into one line.

/* The shorthand pattern: */
background: [color] [image] [position]/[size] [repeat];

/* Example: */
background: url('hero.jpg') center/cover no-repeat;

/* Gradient shorthand: */
background: linear-gradient(135deg, #0071F8, #10b981);

4 Spacing & Sizing Properties

1. padding (Recap from Tutorial 07)

What it does: Space inside the element, between the content and the border.

padding: 20px;                 /* All 4 sides */
padding: 10px 20px;            /* Top/bottom  Left/right */
padding: 10px 20px 30px 40px; /* Top Right Bottom Left (clockwise) */

2. margin (Recap from Tutorial 07)

What it does: Space outside the element, between it and neighboring elements.

margin: 20px;                  /* All 4 sides */
margin: 0 auto;                /* Center horizontally (top/bottom 0, left/right auto) */
margin-bottom: 24px;           /* Just the bottom */

3. gap

What it does: Adds space between children of a flex or grid container. Only works inside display: flex or display: grid.

.container {
  display: flex;
  gap: 20px;       /* 20px between each child */
}

/* Or different row/column gaps: */
row-gap: 20px;
column-gap: 16px;

4. width, max-width, min-width

What they do: Control the horizontal size of an element.

width: 300px;       /* Fixed width */
width: 100%;        /* Fill parent */
max-width: 900px;   /* Never wider than 900px */
min-width: 200px;   /* Never narrower than 200px */
✅ The most common pattern: width: 100% + max-width: 900px + margin: 0 auto. This creates a responsive container that's centered and never gets too wide. We use it on this very page!

5. height, max-height, min-height

height: 400px;       /* Fixed height */
height: 100vh;       /* Full viewport height */
min-height: 500px;   /* At least this tall */
max-height: 80vh;    /* No taller than 80% of viewport */
💡 Pro tip: Avoid setting fixed height on containers with text — the content might overflow! Use min-height instead so it grows with content.

6. overflow

What it does: Controls what happens when content is bigger than its container.

overflow: visible;   /* Content spills out (default) */
overflow: hidden;    /* Content is cut off */
overflow: scroll;    /* Always shows scrollbar */
overflow: auto;      /* Shows scrollbar only when needed */

/* Control each direction separately: */
overflow-x: auto;    /* Horizontal scrollbar if needed */
overflow-y: hidden;  /* Clip vertical overflow */

4. object-fit

What it does: Controls how an <img> or <video> fills its container — crop, fit, or stretch.

6 Pseudo-classes (the : ones)

Pseudo-classes target elements in a specific state (hovered, clicked, focused) or position (first child, third item, etc.). They use a single colon :.

🧠 Think of it this way: A pseudo-class says "select this element, but ONLY WHEN [condition]". Like :hover means "only when the mouse is on it."

6.1 :hover — Mouse is over the element

What it does: Applies styles when the user's mouse is hovering over the element. Works on any element, not just links!

▶ Live Result — Hover the box
Hover over me! I'm a div, not a link.

6.2 :focus — Element is selected/active

What it does: Applies styles when the element is "focused" — clicked into (for inputs) or tabbed to (for buttons/links).

▶ Live Result — Click into the input
✅ Essential for accessibility. Keyboard users navigate with Tab. Without a visible :focus style, they can't see where they are on the page.

6.3 :active — Element is being clicked

What it does: Applies during the split second the mouse button is held down. Use for "pressed button" effects.

▶ Live Result — Click and hold the button

6.4 :visited — Link already clicked

What it does: Styles links the user has already visited. Limited for security — you can only change color-related properties.

a:visited {
  color: #a78bfa;  /* Purple for visited links */
}

6.5 :focus-visible — Focus only for keyboard

What it does: Like :focus, but only triggers for keyboard navigation (Tab), NOT mouse clicks. This is the modern best practice.

button:focus-visible {
  outline: 2px solid #10b981;
  outline-offset: 3px;
}
💡 Modern best practice: Remove the default outline, then add a custom :focus-visible style. Mouse users don't see the focus ring (they don't need it), but keyboard users do.

6.6 :first-child & :last-child

What they do: Target the first or last child element inside a parent.

li:first-child  { font-weight: 700; }    /* Bold first item */
li:last-child   { font-style: italic; }  /* Italic last item */

6.7 :nth-child(n) — The powerful one

What it does: Targets the nth child. Can use numbers, keywords, or formulas.

li:nth-child(2)     { ... }   /* 2nd child */
li:nth-child(odd)   { ... }   /* 1st, 3rd, 5th... (zebra stripes!) */
li:nth-child(even)  { ... }   /* 2nd, 4th, 6th... */
li:nth-child(3n)    { ... }   /* Every 3rd: 3, 6, 9, 12... */

6.8 :only-child

What it does: Targets an element only when it's the sole child of its parent.

p:only-child {
  text-align: center;  /* Center if it's the only paragraph */
}

6.9 :not(selector) — Everything except

What it does: Selects everything that does NOT match the selector. Super useful!

/* All list items EXCEPT the last one get a border-bottom */
li:not(:last-child) {
  border-bottom: 1px solid #2e3f5a;
}

/* All buttons EXCEPT disabled ones get the hover effect */
button:not(:disabled):hover {
  background: #059669;
}

7 Pseudo-elements (the :: ones)

Pseudo-elements create virtual elements that don't exist in your HTML. They're "fake" elements created entirely with CSS. They use double colons ::.

🧠 Key difference:
• Pseudo-class (:) = targets a state → "style this element WHEN it's hovered"
• Pseudo-element (::) = creates a virtual element → "create content before/after this element"

1. ::before

What it does: Creates a virtual element before the content of the selected element.

.label::before {
  content: '🎮 ';    /* REQUIRED — even if empty: content: '' */
}
❌ Critical rule: ::before and ::after absolutely MUST have the content property. Without it, the pseudo-element simply won't appear. Even if you want it empty, you must write content: ''.
