Learn how to build advanced web layouts from scratch by mastering one tiny piece of the Box Model at a time. No complex layouts—just simple rules and their visual outcomes.

Step 01

How to Make a Box & Center It

To build any card or layout, you must first create a container box, give it dimensions, and place it perfectly in the center of the screen.

The Core Rules:

  1. width & height: Declare the exact size of your box.
  2. margin: auto: Centers the box horizontally by telling the browser to split all empty page space evenly on the left and right sides of the box.
HTML Structure
<div class="box"></div>
CSS Stylesheet
.box {
    width: 180px;
    height: 100px;
    background-color: #262936;
    border: 2px solid #ffffff;
    
    /* THE CENTERING MAGIC: Top/Bottom is 0, Left/Right is auto */
    margin: 0 auto; 
}

Step 02

Padding & Text Centering

Now we will put text inside the box. We need to center the lines of text and use padding so the text doesn't touch the borders.

The Core Rules:

  1. text-align: center: Centers the text lines relative to the middle of the box.
  2. padding: Creates protective breathing room inside the box so text never touches the border.
+------------------------------- Box Border -+ | [Padding Space (empty inside)] | | "This is my centered text block | | that wraps cleanly inside" | | [Padding Space] | +--------------------------------------------+
HTML Structure
<div class="box">
    <p>This is centered text protected by padding.</p>
</div>
CSS Stylesheet
.box {
    width: 220px;
    background-color: #121319;
    border: 2px solid #1f222e;
    
    /* 1. Add inner padding to protect text */
    padding: 20px; 
    
    /* 2. Center the text lines */
    text-align: center;
    
    margin: 0 auto;
}

This is centered text protected by padding.

Step 03

Creating Circles & Rounded Badges

How do you make a perfect circular profile picture and a rounded badge container? The answer is explicit dimensions and border-radius.

The Core Rules:

  1. Perfect Circle: The element must have the exact same width and height (a square), and border-radius: 50%.
  2. Pill/Badge: Use a small width, small padding, and a fixed border-radius (like `4px` or `12px`) to round the corners.
HTML Structure
<div class="card">
    <div class="avatar"></div>
    <div class="badge">DEVELOPER</div>
</div>
CSS Stylesheet
/* The Circle Avatar */
.avatar {
    width: 60px;
    height: 60px;
    border-radius: 50%; /* Makes it a circle! */
    background-color: #262936;
    border: 2px solid #ffffff;
    
    /* Centering block element inside card */
    margin: 0 auto 12px auto; 
}

/* The Rounded Badge */
.badge {
    font-size: 10px;
    font-weight: 600;
    color: #ffffff;
    background-color: #262936;
    border: 1px solid #3e4255;
    
    border-radius: 4px; /* Curved corners */
    padding: 3px 8px;
    width: 100px;
    
    margin: 0 auto;
}

Step 04

Left and Right Data Alignment

How do you put a label on the left (e.g. "Bitness") and a value on the right (e.g. "64-bit") side-by-side inside a box without using Flexbox?

The Core Rules:

  1. float: right: Tells the browser to take the value span out of the normal text flow and push it to the far right edge of the row container.
  2. Row Container: A wrapping div that holds the label and value, keeping them grouped on a single line.
+------------------------- Row Container -+ | Label Text | <-- Left-aligned | [Value Span] | <-- floated right! +-----------------------------------------+
HTML Structure
<div class="stats-container">
    <div class="row">Bitness <span class="val">64-bit</span></div>
</div>
CSS Stylesheet
.stats-container {
    background-color: #07080b;
    border: 1px solid #1f222e;
    border-radius: 6px;
    padding: 10px 14px;
}

.row {
    font-size: 12px;
    color: #d1d4dc;
    padding: 4px 0;
    
    /* Clean fix to ensure row wraps floated element height */
    overflow: hidden; 
}

.val {
    color: #ffffff;
    font-weight: 700;
    
    /* THE ALIGNMENT MAGIC: Pushes span to the far right edge! */
    float: right; 
}
Bitness 64-bit
Cache Size 64MB
