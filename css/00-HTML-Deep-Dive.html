HTML: The Deep Dive

Every HTML element you need to build real websites — from the document skeleton to semantic layout, forms, media, and tables. Each element is shown as code AND rendered live so you can see exactly what it produces.

1 The HTML Document Skeleton

The Boilerplate

Every HTML page starts with this exact structure. Memorize it — you'll type it hundreds of times.

<!DOCTYPE html>                <!-- Tells the browser: "This is HTML5" -->
<html lang="en">              <!-- Root element. lang="en" helps screen readers -->
<head>                          <!-- Invisible metadata — NOT rendered on screen -->
    <meta charset="UTF-8">     <!-- Character encoding (supports all languages) -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
                                  <!-- Makes the page responsive on mobile -->
    <title>My Page</title>        <!-- Text shown in browser tab -->
    <link rel="stylesheet" href="style.css">  <!-- External CSS file -->
</head>
<body>                          <!-- Everything visible lives here -->
    <!-- Your content goes here -->
</body>
</html>
💡 Pro Tip: VS Code Shortcut
Type ! and press Tab in VS Code — it auto-generates this entire boilerplate instantly.

What Goes Inside <head>?

TagPurposeExample
<title>Browser tab text + SEO title<title>My Site</title>
<meta>Metadata (charset, viewport, description)<meta name="description" content="...">
<link>External resources (CSS, fonts, icons)<link rel="stylesheet" href="style.css">
<style>Inline CSS inside the HTML file<style> body { color: red; } </style>
<script>JavaScript (also works before </body>)<script src="app.js"></script>

3 Semantic Layout Elements

Why Semantic HTML Matters

Semantic elements describe the meaning of your content — not just how it looks. A <nav> tells the browser "this is navigation," while a <div> means nothing. Search engines, screen readers, and browser tools all benefit from semantic markup.

🏗️ The Golden Rule
Use <div> only when no semantic element fits. If your content IS a header, call it <header>. If it IS navigation, call it <nav>. If it IS the main content, call it <main>.

Full Page Structure

<body>
    <header>            <!-- Top of page: logo, site title, nav -->
        <nav>            <!-- Navigation links -->
            <a href="/">Home</a>
            <a href="/about">About</a>
            <a href="/contact">Contact</a>
        </nav>
    </header>

    <main>              <!-- Primary content (ONE per page) -->
        <section>        <!-- A thematic group of content -->
            <h2>About Us</h2>
            <p>Our story...</p>
        </section>

        <section>
            <h2>Blog Posts</h2>
            <article>    <!-- Self-contained content (a blog post, product, comment) -->
                <h3>Post Title</h3>
                <p>Post content...</p>
            </article>
        </section>

        <aside>          <!-- Sidebar content (tangentially related) -->
            <h3>Related Links</h3>
        </aside>
    </main>

    <footer>            <!-- Bottom of page: copyright, links, legal -->
        <p>&copy; 2026 My Site</p>
    </footer>
</body>

Semantic Elements Cheat Sheet

ElementMeaningWhen to Use
<header>Introductory contentTop of page or section (logo, title, nav)
<nav>NavigationMain site navigation, sidebar nav, breadcrumbs
<main>Primary contentThe core content of the page (ONE per page)
<section>Thematic groupingA section of content with its own heading
<article>Self-contained contentBlog post, product card, comment, news story
<aside>Side contentSidebar, pull quotes, related links
<footer>Closing contentBottom of page or section (copyright, links)
<figure>IllustrationImages, diagrams, code blocks with captions
<figcaption>Caption for figureText describing a figure

The <div> and <span> — Generic Containers

<!-- div = Block container (takes full width, stacks vertically) -->
<div class="card">
    <h3>Card Title</h3>
    <p>Card content...</p>
</div>

<!-- span = Inline container (flows within text, no line break) -->
<p>My favorite color is <span style="color: red;">red</span>.</p>
⚠️ Block vs. Inline
Block elements (div, h1-h6, p, section, header, ul) take the full width and start on a new line.
Inline elements (span, a, strong, em, code, img) flow within text and do NOT start a new line.

4 Images & Media

Images

<!-- Basic image (self-closing tag — no closing tag!) -->
<img src="photo.jpg" alt="A sunset over the ocean">

<!-- With explicit dimensions -->
<img src="logo.png" alt="Company Logo" width="200" height="100">

<!-- Image with figure + caption -->
<figure>
    <img src="chart.png" alt="Revenue chart showing 40% growth">
    <figcaption>Revenue growth in Q4 2025</figcaption>
</figure>
🌐 The alt Attribute is MANDATORY
The alt attribute describes the image for:
1. Screen readers (accessibility for visually impaired users)
2. SEO (search engines read it to understand image content)
3. Broken images (displayed when the image fails to load)
If the image is purely decorative, use alt="" (empty alt).

Video & Audio

<!-- Video (controls = play/pause/volume bar) -->
<video src="intro.mp4" controls width="600">
    Your browser does not support video.
</video>

<!-- Audio -->
<audio src="song.mp3" controls></audio>

<!-- Embed YouTube / external content -->
<iframe src="https://www.youtube.com/embed/VIDEO_ID"
    width="560" height="315"
    frameborder="0"
    allowfullscreen>
</iframe>

5 Forms & Inputs

The Form Element

Forms collect user input. The <form> element wraps all input fields. When submitted, it sends data to a server via the action URL using the method (GET or POST).

<form action="/submit" method="POST">

    <!-- Text input -->
    <label for="name">Name:</label>
    <input type="text" id="name" name="name" placeholder="Enter your name" required>

    <!-- Email (validates email format) -->
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>

    <!-- Password (hidden characters) -->
    <label for="pass">Password:</label>
    <input type="password" id="pass" name="password" minlength="8">

    <!-- Number -->
    <input type="number" min="1" max="100" value="25">

    <!-- Textarea (multi-line text) -->
    <label for="msg">Message:</label>
    <textarea id="msg" name="message" rows="4" placeholder="Write here..."></textarea>

    <!-- Select dropdown -->
    <label for="role">Role:</label>
    <select id="role" name="role">
        <option value="">Choose...</option>
        <option value="dev">Developer</option>
        <option value="design">Designer</option>
    </select>

    <!-- Checkbox -->
    <label><input type="checkbox" name="agree"> I agree to the terms</label>

    <!-- Radio buttons (same name = only one can be selected) -->
    <label><input type="radio" name="plan" value="free"> Free</label>
    <label><input type="radio" name="plan" value="pro"> Pro</label>

    <!-- Submit button -->
    <button type="submit">Send</button>

</form>

🔗 The <label> + for Connection
Always pair every input with a <label>. The label's for attribute must match the input's id. This does two things:
1. Accessibility: Screen readers announce the label when the input is focused.
2. UX: Clicking the label text focuses or toggles the input (especially useful for checkboxes/radios).

8 Putting It Together: Real Website HTML Skeleton

Complete Website Structure

Here's the full HTML skeleton for a typical modern website. This is the exact structure you'll use to clone the practice websites:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <!-- ═══ NAVIGATION ═══ -->
    <header>
        <nav class="navbar">
            <div class="logo">🔥 Brand</div>
            <div class="nav-links">
                <a href="#home">Home</a>
                <a href="#about">About</a>
                <a href="#services">Services</a>
                <a href="#contact">Contact</a>
            </div>
            <button class="cta-btn">Sign Up</button>
        </nav>
    </header>

    <main>
        <!-- ═══ HERO SECTION ═══ -->
        <section id="home" class="hero">
            <h1>Build Something Amazing</h1>
            <p>Subtitle text goes here.</p>
            <div class="hero-buttons">
                <a href="#" class="btn btn-primary">Get Started</a>
                <a href="#" class="btn btn-secondary">Learn More</a>
            </div>
        </section>

        <!-- ═══ FEATURES SECTION ═══ -->
        <section id="services" class="features">
            <h2>Our Services</h2>
            <div class="cards">
                <article class="card">
                    <h3>Web Design</h3>
                    <p>Beautiful responsive websites.</p>
                </article>
                <article class="card">
                    <h3>Development</h3>
                    <p>Clean, maintainable code.</p>
                </article>
                <article class="card">
                    <h3>SEO</h3>
                    <p>Search engine optimization.</p>
                </article>
            </div>
        </section>

        <!-- ═══ CONTACT SECTION ═══ -->
        <section id="contact" class="contact">
            <h2>Contact Us</h2>
            <form>
                <input type="text" placeholder="Name">
                <input type="email" placeholder="Email">
                <textarea placeholder="Message"></textarea>
                <button type="submit">Send</button>
            </form>
        </section>
    </main>

    <!-- ═══ FOOTER ═══ -->
    <footer>
        <div class="footer-columns">
            <div>
                <h4>About</h4>
                <p>We build amazing things.</p>
            </div>
            <div>
                <h4>Links</h4>
                <ul>
                    <li><a href="#">Home</a></li>
                    <li><a href="#">About</a></li>
                </ul>
            </div>
            <div>
                <h4>Contact</h4>
                <p>hello@example.com</p>
            </div>
        </div>
        <p class="copyright">&copy; 2026 Brand. All rights reserved.</p>
    </footer>

</body>
</html>
✅ This is the pattern you'll use for EVERY clone target
1. <header> with <nav> → navbar with logo + links + CTA
2. <main> with <section>s → hero, features, testimonials, etc.
3. <article> → individual cards, posts, products
4. <footer> → columns of links + copyright
5. Style everything with classes → .navbar, .hero, .card, .btn
