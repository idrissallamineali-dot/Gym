💪 Flexbox Katas

20 hands-on CSS Flexbox challenges. Each kata shows you a target layout — your job is to write the CSS that reproduces it. Open your code editor and build each one from scratch.

01Easy

Center a Single Box

Center a single box both horizontally and vertically inside a 300px tall container.

Target Result:

Centered
Use only display: flex, justify-content, and align-items. 3 properties max.

Solution

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 300px;
}

20Hard

Responsive Flex to Stack

Build a 3-column row layout that automatically stacks into a single column on small screens. The transition point should be around 600px viewport width.

Use flex-wrap: wrap and flex: 1 1 250px on each item. As the viewport shrinks below ~600px, the 250px basis forces items to wrap to a full row each. Alternatively, use a media query to switch flex-direction.

Solution (No Media Query)

/* Pure Flexbox — no media query needed! */
.container {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
}
.item {
    flex: 1 1 250px;
    /* Each item wants 250px minimum.
       On wide screens: 3 fit in one row.
       On narrow screens: items wrap to their own row. */
}

/* Alternative: Media Query approach */
@media (max-width: 600px) {
    .container {
        flex-direction: column;
    }
}
