Arrow Functions & Lexical `this`

Implement a Countdown class whose constructor accepts the starting count `seconds`. It contains a `start()` method that logs the count to the console once every second and decrements it. When it hits `0`, it logs `"Boom!"` and terminates the interval.

const timer = new Countdown(3);

// (After 1s) -> 3
// (After 2s) -> 2
// (After 3s) -> 1
// (After 4s) -> "Boom!"
Do NOT use `.bind()`, `var self = this`, `var that = this`, or standard functions inside `setInterval`. Use arrow functions to preserve lexical scope.

Solution

class Countdown {
    constructor(seconds) {
        this.seconds = seconds;
    }

    start() {
        const intervalId = setInterval(() => {
            if (this.seconds > 0) {
                console.log(this.seconds);
                this.seconds--;
            } else {
                console.log("Boom!");
                clearInterval(intervalId);
            }
        }, 1000);
    }
}

09 Medium

For...of Map Iterator

Write a function findMaxScore(studentMap) that takes a `Map` of `{ studentName => score }` pairs and returns an object `{ student, score }` representing the student with the highest score.

const grades = new Map([["Alice", 92], ["Bob", 98], ["Charlie", 85]]);
findMaxScore(grades); // { student: "Bob", score: 98 }
Use the `for...of` loop to iterate over the Map. Destructure the key-value array parameter directly inside the loop's declaration.

Solution

function findMaxScore(studentMap) {
    let maxScore = -Infinity;
    let topStudent = null;

    // Destructuring [name, score] directly in for...of loop:
    for (const [name, score] of studentMap) {
        if (score > maxScore) {
            maxScore = score;
            topStudent = name;
        }
    }

    return { student: topStudent, score: maxScore };
}

11 Medium

WeakSet Object Tagging

Implement a tagging utility object messageTracker that allows tagging objects as read using markAsRead(msg) and checking status using isRead(msg). The tagging system must not modify the original objects and must allow unused objects to be garbage-collected normally.

const m1 = { text: "Hello" };
const m2 = { text: "World" };
messageTracker.markAsRead(m1);
messageTracker.isRead(m1); // true
messageTracker.isRead(m2); // false
Use an internal `WeakSet` encapsulated inside the tracking utility. Do NOT append properties directly to the objects.

Solution

const messageTracker = (() => {
    const readStore = new WeakSet();
    return {
        markAsRead(msg) {
            readStore.add(msg);
        },
        isRead(msg) {
            return readStore.has(msg);
        }
    };
})();

// Since readStore is a WeakSet, it holds weak references to objects.
// If objects m1 or m2 are dereferenced elsewhere, they are garbage-collected safely.
12 Hard

Map for Multi-Type Memoization

Write a higher-order function memoize(fn) that returns a memoized wrapper around fn. The memoized function must support caching results for arguments of any type, including object references and primitives.

const processor = (obj) => ({ val: obj.x * 2 });
const memoized = memoize(processor);

const input = { x: 5 };
memoized(input); // Calculated and cached
memoized(input); // Returned directly from cache
Use an ES6 `Map` inside a closure to manage the cache keys. Since Maps support Object references as unique keys, this is highly efficient.

Solution

function memoize(fn) {
    const cache = new Map();
    return function(arg) {
        if (cache.has(arg)) {
            return cache.get(arg);
        }
        const result = fn(arg);
        cache.set(arg, result);
        return result;
    };
}
13 Hard

WeakMap Private State Encapsulation

Create a class SecretAgent whose constructor accepts `name` and `secretCode`. The class exposes `getName()` normally, but keeps the `secretCode` completely private. A method `verifyCode(code)` returns a boolean if the code matches.

const bond = new SecretAgent("James Bond", "007");
bond.getName();           // "James Bond"
bond.verifyCode("007");   // true
bond.verifyCode("123");   // false
Object.keys(bond);        // ["name"] — no secretCode property visible!
Use a `WeakMap` inside a closure or module scope to manage private properties, using `this` as the WeakMap key. Do NOT store the secret on properties prefixed with `_` or Symbol keys.

Solution

const SecretAgent = (() => {
    const privates = new WeakMap();

    return class {
        constructor(name, secretCode) {
            this.name = name;
            // Store private state mapping this instance to private values
            privates.set(this, { secretCode });
        }

        getName() {
            return this.name;
        }

        verifyCode(code) {
            const privateData = privates.get(this);
            return privateData ? privateData.secretCode === code : false;
        }
    };
})();
14 Hard

Custom Iterable Range (FizzBuzz Range)

Write a factory function createFizzBuzzRange(start, end) that returns an object representing a range of numbers. The object must be **iterable** directly in a for...of loop. Instead of numbers divisible by 3, it should yield `"Fizz"`; instead of 5, `"Buzz"`; and instead of 15, `"FizzBuzz"`.

for (const item of createFizzBuzzRange(13, 16)) {
    console.log(item); 
}
// Logs:
// 13
// 14
// "FizzBuzz"
// 16
Do NOT use generators. Manually implement the Iterable and Iterator protocols by adding `[Symbol.iterator]` to the range object returning an iterator with a conforming `.next()` method.

Solution

function createFizzBuzzRange(start, end) {
    return {
        [Symbol.iterator]() {
            let current = start;
            return {
                next() {
                    if (current <= end) {
                        let value = current;
                        if (value % 15 === 0) value = "FizzBuzz";
                        else if (value % 3 === 0) value = "Fizz";
                        else if (value % 5 === 0) value = "Buzz";
                        
                        current++;
                        return { value, done: false };
                    }
                    return { value: undefined, done: true };
                }
            };
        }
    };
}
15 Medium

Generator-Based Infinite Fibonacci

Implement a generator function fibonacciGenerator() that yields Fibonacci numbers infinitely, starting with `0` and `1`.

const gen = fibonacciGenerator();
gen.next().value; // 0
gen.next().value; // 1
gen.next().value; // 1
gen.next().value; // 2
gen.next().value; // 3
Use ES6 Generator syntax (function*) and the yield keyword. No recursion. No static memory arrays.

Solution

function* fibonacciGenerator() {
    let prev = 0;
    let curr = 1;
    yield prev;
    yield curr;
    
    while (true) {
        const next = prev + curr;
        yield next;
        prev = curr;
        curr = next;
    }
}

Recursive Flat Array Traverser (yield*)

Write a generator function flattenGenerator(arr) that yields items from an infinitely nested array structure in flat, sequential order.

const nested = [1, [2, [3, 4]], 5];
const flatValues = [...flattenGenerator(nested)]; 
// [1, 2, 3, 4, 5]
Use ES6 Generator recursion. You must delegate to nested generators using the yield* statement.

Solution

function* flattenGenerator(arr) {
    for (const item of arr) {
        if (Array.isArray(item)) {
            // yield* delegates the iteration control recursively to the nested generator:
            yield* flattenGenerator(item);
        } else {
            yield item;
        }
    }
}
17 Hard

Safe Type-Checking Object Proxy

Write a function createTypeSafeUser(user) that returns a wrapped proxy version of the user object. The proxy must guard changes to age (throwing a TypeError if set to a non-number or negative value) and email (throwing an Error if set to a string not containing `@`). Attempting to set undefined keys must throw a reference error.

const safeUser = createTypeSafeUser({ name: "Idris", age: 25 });
safeUser.age = "thirty"; // TypeError: age must be a positive number
safeUser.email = "hello"; // Error: invalid email format
safeUser.role = "admin";  // ReferenceError: Property "role" does not exist
Use an ES6 `Proxy` and configure a dynamic `set` handler trap.

Solution

function createTypeSafeUser(user) {
    return new Proxy(user, {
        set(target, prop, value) {
            // Guard non-existent property declarations
            if (!(prop in target)) {
                throw new ReferenceError(`Property "${prop}" does not exist`);
            }

            if (prop === "age") {
                if (typeof value !== "number" || value < 0 || Number.isNaN(value)) {
                    throw new TypeError("age must be a positive number");
                }
            }

            if (prop === "email") {
                if (typeof value !== "string" || !value.includes("@")) {
                    throw new Error("invalid email format");
                }
            }

            target[prop] = value;
            return true; // Return true to indicate successful assignment
        }
    });
}
18 Medium

Custom Promisify Wrapper

Implement a utility function promisify(callbackFn) that converts standard Node-style callback functions `(args..., callback(err, result))` into modern promise-returning operations.

const mockAsyncAPI = (id, cb) => {
    setTimeout(() => id === 1 ? cb(null, "User One") : cb("User not found"), 50);
};

const getUserPromise = promisify(mockAsyncAPI);
getUserPromise(1)
    .then(res => console.log(res)) // "User One"
    .catch(err => console.error(err));
Use the ES6 `new Promise` constructor and the rest/spread operators. No external shims or libraries.

Solution

const promisify = (fn) => {
    return function(...args) {
        return new Promise((resolve, reject) => {
            // Inject custom callback as final argument
            fn(...args, (err, result) => {
                if (err) return reject(err);
                resolve(result);
            });
        });
    };
};
19 Medium

Subclassing with Super

Create a class Employee whose constructor sets `name` and `salary`, containing a `getDetails()` method. Create a subclass Developer extending `Employee` whose constructor takes `name`, `salary`, and `specialty`. It must override `getDetails()` to append the specialty to the parent details.

const dev = new Developer("Idris", 120000, "JavaScript");
dev.getDetails(); 
// "Employee Idris earns $120000 specializing in JavaScript"
Use ES6 Class Syntax (`class`, `extends`, and `super()`) to inherit and delegate parent behaviors.

Solution

class Employee {
    constructor(name, salary) {
        this.name = name;
        this.salary = salary;
    }

    getDetails() {
        return `Employee ${this.name} earns $${this.salary}`;
    }
}

class Developer extends Employee {
    constructor(name, salary, specialty) {
        // Invoke parent constructor to set common fields
        super(name, salary);
        this.specialty = specialty;
    }

    getDetails() {
        // Delegate to parent method and extend functionality
        return `${super.getDetails()} specializing in ${this.specialty}`;
    }
}
20 Hard

Safe Polyfill for `Array.prototype.find`

Build a secure, robust polyfill for the ES6 Array.prototype.find(callback[, thisArg]) method. The polyfill must check for valid object context, verify the callback exists, iterate properly, support custom lexical scopes, and prevent enumeration.

[1, 2, 3].find(x => x > 1); // 2
Use `Object.defineProperty` to add the method safely to the prototype. Implement proper type validation and standard-compliant loop behaviors.

Solution

if (!Array.prototype.find) {
    Object.defineProperty(Array.prototype, 'find', {
        value: function(callback, thisArg) {
            // 1. Guard check for null context
            if (this == null) {
                throw new TypeError('"this" is null or not defined');
            }

            // 2. Coerce context to Object
            const O = Object(this);
            const len = O.length >>> 0; // Convert to unsigned 32-bit int

            // 3. Verify callback function
            if (typeof callback !== 'function') {
                throw new TypeError('callback must be a function');
            }

            // 4. Iterate and invoke callback under targeted context
            for (let i = 0; i < len; i++) {
                if (callback.call(thisArg, O[i], i, O)) {
                    return O[i];
                }
            }

            return undefined;
        },
        writable: true,
        configurable: true
    });
}
