4.reduce() — Boil an array down to one value

.reduce(fn, initialValue) — Starts with initialValue, then for each item calls fn(accumulator, item). Whatever you return becomes the new accumulator. Returns the final accumulator.

reduce mental model: array: [ 1, 2, 3, 4 ] initialValue: 0 Step 1: acc=0 + item=1 → returns 1 Step 2: acc=1 + item=2 → returns 3 Step 3: acc=3 + item=3 → returns 6 Step 4: acc=6 + item=4 → returns 10 ← final result [1,2,3,4].reduce((acc, item) => acc + item, 0) → 10

① Sum

[1,2,3,4].reduce((sum,n) => sum+n, 0)
1 + 2 + 3 + 4 = 10

② Product — multiply all values

const nums = [1, 2, 3, 4, 5];
const product = nums.reduce((prod, n) => prod * n, 1);
// 1*1=1 → 1*2=2 → 2*3=6 → 6*4=24 → 24*5=120
console.log(product); // 120

③ Max value — no Math.max needed

const scores = [72, 95, 88, 61, 99, 74];
const max = scores.reduce((m, n) => n > m ? n : m, -Infinity);
// 99

const min = scores.reduce((m, n) => n < m ? n : m, Infinity);
// 61

6Quick Methods — some, every, includes, flat, flatMap, Array.from

.some() — is there at least one match?

.some(fn) — Returns true if any item passes. Short-circuits on first match.

[1,2,3].some(n => n > 2)
true
[1,2,3].some(n => n > 10)
false
users.some(u => u.isAdmin)
→ true if ANY user is admin
use case: show admin panel?

.every() — do ALL items match?

.every(fn) — Returns true only if every item passes. Short-circuits on first failure.

[2,4,6].every(n => n%2===0)
true
[2,3,6].every(n => n%2===0)
false
fields.every(f => f.value !== '')
→ form validation!
enable Submit only if all filled

.includes() — does array contain this exact value?

.includes(val) — Strict equality check (===). Works great for primitives.

['a','b','c'].includes('b')
true
['a','b','c'].includes('z')
false
allowedRoles.includes(user.role)
→ permission check!
['admin','mod'].includes('admin') → true

.flat() — flatten nested arrays

.flat(depth) — Flattens nested arrays. Default depth is 1. Use Infinity for any depth.

[[1,2],[3,4]].flat()
[[1,2],[3,4]]
↓ depth: 1
[1, 2, 3, 4]
[1,[2,[3,[4]]]].flat(Infinity)
[1,[2,[3,[4]]]]
↓ depth: Infinity
[1, 2, 3, 4]

.flatMap() — map then flatten (depth 1)

.flatMap(fn) — Like .map() but flattens the result one level. Great when your map returns arrays.

sentences.flatMap(s => s.split(' '))
['Hello world', 'foo bar']
↓ split each, then flatten
['Hello','world','foo','bar']
users.flatMap(u => u.hobbies)
each user has hobbies array
↓ collect all hobbies flat
['coding','gaming','reading',...]

Array.from() — Turns NodeLists, Sets, Maps, strings, and any iterable into a real array.

[...new Set(arr)] — remove duplicates

A Set only stores unique values. Spreading it back into an array gives you a deduplicated array instantly.

[...new Set([1,2,2,3,3,3])]
[1, 2, 2, 3, 3, 3]
↓ new Set → {1,2,3} → spread
[1, 2, 3]

↓ unique only
['js', 'css', 'html']

SOLUTION
const capitalize = str =>
  str.split(' ')
     .map(w => w[0].toUpperCase() + w.slice(1))
     .join(' ');

const cleanData = rawData
  .filter(u => u.is_active === 1)
  .map(u => ({
    id:       Number(u.user_id),
    name:     capitalize(u.full_name),
    email:    u.email_addr.toLowerCase(),
    isActive: u.is_active === 1,
    age:      parseInt(u.age_years),
    score:    parseFloat(u.score),
  }));

console.log(cleanData);
