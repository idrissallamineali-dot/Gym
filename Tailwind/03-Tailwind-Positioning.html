§01

The 5 Position Types

CSS has 5 position values. Tailwind maps each to a single utility class. Here's the full translation table plus when to reach for each one.

💡

The Golden Rule of Absolute Positioning

absolute elements position themselves relative to their nearest ancestor that has position: relative (or absolute/fixed/sticky). If no such ancestor exists, they fall back to the entire page (viewport) — almost never what you want.

§02

relative + absolute — The Most Used Combo

This pattern appears in every gaming site: price badges, discount ribbons, "NEW" labels. The parent is the coordinate system; the child floats anywhere inside it.

How It Works

STEP 1 — Give the parent relative:

<div class="relative w-[300px] h-[350px]">
<img class="w-full h-full object-cover">
<span class="absolute bottom-3 right-3...">
<!-- badge -->
</span>
</div>

The relative parent becomes the "box" that absolute children measure from. top: 0 = top edge of this div, not the page.

Raw CSS equivalent:

.card {
position: relative;
}
.badge {
position: absolute;
bottom: 12px;
right: 12px;
}

⚠️

Negative Margin Trick: -mt-24

For overlapping sections (like feature cards that overlap the hero), you often use negative margin rather than absolute positioning. This keeps the element in the document flow while pulling it up over the previous section.

-mt-24 → margin-top: -96px /* pulls element UP by 96px */
-mt-[60px] → margin-top: -60px /* arbitrary negative margin */
§04

Centering with absolute + translate

The most reliable way to center an element of unknown size over its parent. You'll use this for overlays, badges, spinners, and labels constantly.

STEP 1

Parent: relative

relative w-[...] h-[...]

Creates the coordinate system. Child will measure from this element's top-left corner.

STEP 2

Child: absolute top-1/2 left-1/2

top: 50%; left: 50%

Moves the element's top-left corner to the exact center of the parent. Still off — the element is bottom-right of center.

STEP 3

Add: -translate-x-1/2 -translate-y-1/2

transform: translate(-50%, -50%)

Shifts the element LEFT by half its own width and UP by half its own height. Now perfectly centered! ✅

// Full centering pattern:
absolute top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2
// CSS equivalent:
position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%);

§05

fixed — Pinned to the Viewport

fixed removes the element from document flow entirely and pins it to the browser window. It does NOT move when the user scrolls. Always pair it with z-50 to keep it on top.

Pattern 1: Sticky Navbar

<header class="
fixed
top-0 left-0 right-0
z-50
bg-[#121319]
">
fixed → position: fixed
top-0 left-0 right-0 → spans full width at top
z-50 → z-index: 50 (stays on top)

Pattern 2: Floating Action Button

<button class="
fixed
bottom-6 right-6
z-50
w-14 h-14 rounded-full
bg-blue-500 text-white
">+</button>

Always visible, bottom-right of the screen. Perfect for chat buttons, scroll-to-top, or add buttons.

Why z-50?

Fixed elements are removed from the flow, but they still stack with other positioned elements. Without a z-index, a fixed navbar can be hidden behind a modal, image, or dropdown. Always give navbars a high z-index like z-50 so they stay on top.

§06

sticky — Follows Then Pins

Sticky is like relative until the element hits the scroll threshold, then it acts like fixed. It stays IN the document flow — the page reserves its space.

fixed Always on screen

  • → Removed from document flow
  • → Always visible, even on a short page
  • → Content can scroll behind it (you need padding-top on body)
  • → Use for: site navbars, cookie banners, chat buttons

sticky Scrolls then pins

  • → Stays in document flow
  • → Only sticks within its parent container
  • → No need for padding compensation
  • → Use for: section headers, table headers, sidebars
// Sticky section header:
sticky top-0 z-10 bg-[#0b0c10] px-4 py-3
// CSS equivalent:
position: sticky; top: 0; z-index: 10;
/* top: 0 = "stick when my top edge hits 0px from the scroll container's top" */

§07

z-index — Stacking Order

When positioned elements overlap, z-index controls which one appears on top. Higher number = closer to the user. Only works on positioned elements (not static).

z-index translation table
z-0z-index: 0
z-10z-index: 10
z-20z-index: 20
z-30z-index: 30
z-40z-index: 40
z-50z-index: 50
z-[100]z-index: 100 (arbitrary)
-z-10z-index: -10 (behind everything)

Common z-index Strategy

z-0
Page Content
Normal article, cards, images
z-10
Dropdowns / Tooltips
Must appear above page content
z-30
Modals / Overlays
Covers all page content
z-50
Navbar / Toast alerts
Stays on top of everything
-z-10
Background decorations
Behind all other content

§08

overflow — Clipping Children

When children are bigger than their parent, or positioned children extend outside their parent, overflow controls what happens. Critical for image cards with rounded corners!

Tailwind Class
Raw CSS
Behavior
overflow-hidden
overflow: hidden
Clips anything outside the box. Use with rounded-xl!
overflow-visible
overflow: visible
Default. Everything shows, even outside the box.
overflow-scroll
overflow: scroll
Always shows scrollbar, even if not needed.
overflow-auto
overflow: auto
Only shows scrollbar when content overflows.
overflow-x-hidden
overflow-x: hidden
Clips horizontal overflow only (fixes horizontal scroll bugs).
overflow-y-auto
overflow-y: auto
Vertical scroll only when needed (sidebar lists).
