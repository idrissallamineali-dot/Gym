Tailwind Flexbox Mastery

CSS ➜ Tailwind Series

You already understand Flexbox in raw CSS — display: flex, justify-content, align-items, the whole model. This tutorial maps every property you know to its Tailwind utility class, then puts it all into practice with live demos.

💡

Every live demo below is rendered with only Tailwind classes. No custom CSS. Open DevTools and inspect any element to see exactly which utilities are applied.

Section 1 — The Complete Translation Table

Every raw CSS Flexbox property mapped to its Tailwind utility class.

Raw CSS Tailwind Class What It Does
display: flex flex Turns the element into a flex container
flex-direction: column flex-col Stacks children vertically instead of horizontally
flex-direction: row flex-row Default: children placed horizontally (left to right)
justify-content: flex-start justify-start Pack items to the start of the main axis
justify-content: center justify-center Center items along the main axis
justify-content: flex-end justify-end Pack items to the end of the main axis
justify-content: space-between justify-between First item at start, last at end, equal space in between
justify-content: space-around justify-around Equal space around each item (half-size at edges)
justify-content: space-evenly justify-evenly Truly equal space between and around every item
align-items: center items-center Center items on the cross axis
align-items: flex-start items-start Align items to the start of the cross axis
align-items: flex-end items-end Align items to the end of the cross axis
align-items: stretch items-stretch Stretch items to fill the cross axis (default)
align-self: flex-start self-start Override align-items for a single child — push to start
align-self: center self-center Override align-items for a single child — center
align-self: flex-end self-end Override align-items for a single child — push to end
flex-wrap: wrap flex-wrap Allow items to wrap onto multiple lines
flex-shrink: 0 shrink-0 Prevent the item from shrinking below its natural size
flex-grow: 1 grow Allow the item to grow and fill remaining space
gap: 16px gap-4 Add 1rem (16px) gap between flex/grid children

📏 Gap Scale Reference

Tailwind's spacing scale uses a 4px base unit. So gap-1 = 4px, gap-2 = 8px, gap-4 = 16px, gap-8 = 32px, etc.

gap-1 → 4px gap-2 → 8px gap-3 → 12px gap-4 → 16px gap-6 → 24px gap-8 → 32px

Section 6 — flex-shrink and flex-grow

Two of the most practical utilities: shrink-0 protects an element's size, and grow tells it to absorb all remaining space.

shrink-0 — Protecting an Avatar from Getting Squished flex-shrink: 0

Without shrink-0, a circle avatar gets crushed when text is long:

❌ Without shrink-0
👤

This is a really long description text that will cause the avatar to shrink down and look horrible because flex shrink is on by default.

✅ With shrink-0
👤

This is a really long description text and the avatar stays perfectly circular thanks to shrink-0 protecting its width.

<div class="flex items-center gap-3">
  <div class="w-12 h-12 rounded-full shrink-0">👤</div>
  <p>Long text that can't squish the avatar...</p>
</div>

/* Raw CSS */
.avatar {
  width: 48px;
  height: 48px;
  flex-shrink: 0;  /* NEVER shrink below 48×48 */
}
grow — Search Bar Filling Remaining Space flex-grow: 1
Logo
<div class="flex items-center gap-3">
  <div class="shrink-0">Logo</div>
  <input class="grow" placeholder="Search...">
  <button class="shrink-0">Profile</button>
</div>

/* Raw CSS */
.logo    { flex-shrink: 0; }
.search  { flex-grow: 1; }   /* absorbs ALL remaining horizontal space */
.profile { flex-shrink: 0; }

  <span class="self-start">New</span>     <!-- badge pushed LEFT  -->

/* Raw CSS */
.badge-left   { align-self: flex-start; }
.badge-right  { align-self: flex-end; }
.badge-center { align-self: center; }
🔑

Key insight: In flex-col, the cross axis is horizontal, so self-start means LEFT and self-end means RIGHT. The axes flip compared to flex-row!

🧠 Patterns Used in This Dashboard

flex items-center justify-between

Header — push items to opposite edges

flex flex-wrap gap-4

Card grid — responsive wrapping layout

flex flex-col gap-3 justify-between

Card internals — stacked with footer pushed down

shrink-0

Protect fixed-size elements (avatars, icons)

grow

Fill remaining space (descriptions, search bars)

self-start / self-end

Position badges independently within cards
