Tutorial 01

Tailwind Foundations

Everything you already know about CSS — repackaged into short utility classes you write directly in your HTML. No new language, no magic.

01

What is Tailwind CSS?

Tailwind is NOT a new language. It is raw CSS repackaged into short, single-purpose class names called utility classes.

Instead of writing CSS rules in a separate .css file, you apply styles directly in your HTML by adding classes. Every Tailwind class maps to exactly one (or a small group of) CSS property.

For example, the Tailwind class p-4 is just padding: 1rem;. That's it. No abstraction, no framework magic.

Side-by-Side: Raw CSS vs Tailwind

Raw CSS 
.card {
  background: #121319;
  padding: 24px;
  border-radius: 12px;
  border: 1px solid #1f222e;
  color: #ffffff;
  font-size: 14px;
}

<div class="card">
  Hello, CSS!
</div>
Tailwind (no CSS file needed) 
<div class="bg-cardBg
             p-6
             rounded-xl
             border border-borderSlate
             text-white
             text-sm">
  Hello, Tailwind!
</div>

Live Result (both look identical)

Hello, Tailwind! — This box is styled entirely with utility classes.

CDN Setup — One Line

To start using Tailwind instantly, add this single script tag inside your <head>:

HTML <head> 
<script src="https://cdn.tailwindcss.com"></script>

That's it. No npm, no build step, no config files. Open the HTML file in your browser and every Tailwind class will work.

02

The Spacing System

Spacing is the single most important system in Tailwind. It controls padding, margin, gap, and more. Every spacing value is a multiple of 4px.

The number in the class is a multiplier: p-1 = 4px, p-2 = 8px, p-4 = 16px, and so on.

04

Colors & Backgrounds

Tailwind ships with a built-in color palette. Each color has shades from 50 (lightest) to 950 (darkest). The pattern is: {property}-{color}-{shade}.

You can also use any custom hex color with the arbitrary value syntax: bg-[#121319].

In raw CSS you set display: flex;. In Tailwind you just write the class flex. Same property, shorter syntax.

Tailwind CSS Equivalent Use Case

inlinedisplay: inline;Default for spans
flexdisplay: flex;Flex container
griddisplay: grid;Grid container
hiddendisplay: none;Hide element completely

overflow-autooverflow: auto;Scroll when needed

The Code — Every Class Explained

HTML 
/* ── Card wrapper ── */
<div class="w-full            /* width: 100% */
            max-w-sm         /* max-width: 24rem (384px) */
            bg-cardBg        /* background: #121319 */
            border           /* border-width: 1px */
            border-borderSlate /* border-color: #1f222e */
            rounded-2xl      /* border-radius: 1rem */
            overflow-hidden  /* overflow: hidden */">

  /* ── Cover strip ── */
  <div class="h-24             /* height: 6rem (96px) */
              bg-gradient-to-r /* gradient direction: right */
              from-slate-800   /* gradient start color */
              to-slate-700">   /* gradient end color */
  </div>

  /* ── Content area ── */
  <div class="px-6 pb-6">     /* padding x:24px, bottom:24px */

    /* ── Avatar ── */
    <div class="-mt-10 mb-4">   /* negative top margin pulls up */
      <div class="w-20 h-20      /* 80px × 80px */
                  rounded-full   /* perfect circle */
                  bg-slate-600   /* background color */
                  border-4       /* 4px border */
                  border-cardBg  /* border matches card bg */
                  flex items-center justify-center
                  text-2xl font-bold text-white">
        JD
      </div>
    </div>

    /* ── Name ── */
    <h3 class="text-xl font-semibold text-white tracking-tight">
      Jane Doe
    </h3>

    /* ── Subtitle ── */
    <p class="text-sm text-textMuted mt-0.5">
      Frontend Engineer · London
    </p>

    /* ── Bio ── */
    <p class="text-sm text-textMuted mt-4 leading-relaxed">
      Building beautiful interfaces...
    </p>

    /* ── Stats row ── */
    <div class="flex gap-6        /* flexbox with 24px gaps */
                mt-5 pt-5       /* spacing above + inside */
                border-t        /* top border only */
                border-borderSlate">
      <div>
        <p class="text-white font-semibold text-lg">128</p>
        <p class="text-textMuted text-xs uppercase tracking-wide">Projects</p>
      </div>
      /* ...repeat for Followers, Following */
    </div>
  </div>
</div>

Key Takeaway

The Tailwind version and the raw CSS version produce the exact same result. The difference is where you write the styles. With Tailwind, everything lives in the HTML — no switching between files, no inventing class names, no cascade surprises. You already know the CSS; Tailwind just gives you a faster way to apply it.
