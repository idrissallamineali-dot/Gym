04 — Loops

How to repeat actions efficiently. Loops are the engine behind processing lists, building UIs, and handling data at scale.

1. What Is a Loop?

A loop is a structure that repeats a block of code as long as a condition remains true. Without loops, you would need to write the same code over and over for every item:

// Without a loop (repetitive, fragile, does not scale):
console.log(students[0]);
console.log(students[1]);
console.log(students[2]);
console.log(students[3]);
// What if there are 10,000 students?

// With a loop (scalable, clean):
for (let i = 0; i < students.length; i++) {
    console.log(students[i]);
}

Every loop has three core elements:

  1. Initialization — setting a starting point (e.g., counter = 0).
  2. Condition — checked before each iteration; if false, the loop stops.
  3. Update — modifying the counter so the loop eventually ends.
[ Initialize counter ] │ ▼ ┌──────────────────┐ │ Is condition true? │◄──────────────┐ └──────────────────┘ │ │ │ │ YES NO │ │ │ │ ▼ ▼ │ [ Execute body ] [ Exit loop ] │ │ │ ▼ │ [ Update counter ] ────────────────┘

2. The for Loop (The Classic)

The most common loop. All three elements (initialization, condition, update) are declared on a single line.

//     initialization;  condition;    update
for (let i = 0;        i < 5;        i++) {
    console.log("Iteration:", i);
}
// Output: 0, 1, 2, 3, 4

Step-by-step execution trace:

StepiCondition i < 5Action

21trueExecute body, log 1, then i++ → i becomes 2
32trueExecute body, log 2, then i++ → i becomes 3
43trueExecute body, log 3, then i++ → i becomes 4

65falseLoop exits

2.1 — Looping Through an Array

This is by far the most common use case for for loops:

const colors = ["red", "green", "blue"];

for (let i = 0; i < colors.length; i++) {
    console.log(colors[i]);
}
// "red", "green", "blue"
Why i < array.length and not i <= array.length? Arrays are zero-indexed: the first element is at index 0, the last is at index length - 1. If you use <=, you will access one index beyond the array, which returns undefined.

["a", "b", "c"] → length is 3, valid indices are 0, 1, 2.

2.2 — Looping Backwards

const nums = [10, 20, 30];

for (let i = nums.length - 1; i >= 0; i--) {
    console.log(nums[i]);
}
// 30, 20, 10

2.3 — Nested Loops

A loop inside a loop. The inner loop runs completely for each single iteration of the outer loop.

for (let row = 1; row <= 3; row++) {
    for (let col = 1; col <= 3; col++) {
        console.log(`Row ${row}, Col ${col}`);
    }
}
// Row 1 Col 1, Row 1 Col 2, Row 1 Col 3,
// Row 2 Col 1, Row 2 Col 2, Row 2 Col 3,
// Row 3 Col 1, Row 3 Col 2, Row 3 Col 3
Performance warning Nested loops multiply iterations. An outer loop of 1,000 × an inner loop of 1,000 = 1,000,000 iterations. Be careful with nested loops on large datasets.

3. The while Loop

The while loop checks the condition before each iteration. If the condition is false from the start, the body never executes.

let count = 0;

while (count < 5) {
    console.log("Count:", count);
    count++;  // Don't forget to update! Otherwise → infinite loop
}
// 0, 1, 2, 3, 4

When to use while instead of for:

Use while when you don't know in advance how many iterations you need — the loop continues until a condition changes.

// Example: keep asking for input until valid
let password = "";

while (password !== "secret123") {
    password = prompt("Enter password:");
}
console.log("Access granted!");

4. The do...while Loop

The do...while loop checks the condition after each iteration. This guarantees the body executes at least once, even if the condition is false.

let num = 10;

do {
    console.log("This runs at least once! num =", num);
    num++;
} while (num < 5);

// Output: "This runs at least once! num = 10"
// The condition (10 < 5) is false, but the body already ran once

Comparison:

Featurewhiledo...while
Condition checkedBefore the bodyAfter the body
Minimum executions0 (if condition is false immediately)1 (body always runs at least once)

5. break and continue

These two keywords give you fine-grained control over loop execution.

5.1 — break: Exit the Loop Immediately

When the engine hits break, it stops the loop entirely, no matter how many iterations are left.

const numbers = [1, 2, 3, 4, 5, 6, 7, 8];

for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] === 5) {
        console.log("Found 5! Stopping.");
        break;  // Exit the loop immediately
    }
    console.log(numbers[i]);
}
// Output: 1, 2, 3, 4, "Found 5! Stopping."
// 6, 7, 8 are never processed

5.2 — continue: Skip to the Next Iteration

continue skips the rest of the current iteration and jumps straight to the next one.

for (let i = 1; i <= 10; i++) {
    if (i % 2 !== 0) {
        continue;  // Skip odd numbers
    }
    console.log(i);
}
// Output: 2, 4, 6, 8, 10 (only even numbers)
When to use each break = you found what you needed, no reason to keep looping.
continue = this particular item is not relevant, skip it and check the next one.

6. for...in Loop (Iterating Over Object Keys)

The for...in loop iterates over the enumerable property names (keys) of an object.

const user = {
    name: "Idris",
    age: 25,
    role: "Developer"
};

for (let key in user) {
    console.log(key, "→", user[key]);
}
// "name → Idris"
// "age → 25"
// "role → Developer"
Do NOT use for...in on arrays for...in iterates over keys (which for arrays are the string indices "0", "1", "2"...). It can also pick up inherited prototype properties. Use for...of or a standard for loop for arrays instead. 
// ❌ BAD — for...in on an array
const arr = ["a", "b", "c"];
for (let index in arr) {
    console.log(typeof index);  // "string" — indices are strings, not numbers!
}

// ✅ GOOD — for...of on an array
for (let value of arr) {
    console.log(value);  // "a", "b", "c"
}

7. for...of Loop (ES6 — Iterating Over Values)

The for...of loop iterates over iterable objects — arrays, strings, Maps, Sets, and more. It gives you the values directly, not the indices.

const fruits = ["apple", "banana", "cherry"];

for (const fruit of fruits) {
    console.log(fruit);
}
// "apple", "banana", "cherry"

Works on strings (iterates over each character):

for (const char of "Hello") {
    console.log(char);
}
// "H", "e", "l", "l", "o"

Supports break and continue (unlike forEach!):

const nums = [1, 2, 3, 4, 5];

for (const n of nums) {
    if (n === 3) break;    // ✅ Works! Stops the loop
    console.log(n);
}
// 1, 2
for...of is the modern standard for iterating arrays It is cleaner than a for loop (no index management), and more powerful than forEach (supports break/continue). This is your go-to for arrays in ES6 code.

If you also need the index, use entries():

const colors = ["red", "green", "blue"];

for (const [index, color] of colors.entries()) {
    console.log(`${index}: ${color}`);
}
// "0: red", "1: green", "2: blue"

9. Infinite Loops

An infinite loop runs forever because the condition never becomes false. This freezes your browser tab or crashes your Node.js process.

// ❌ INFINITE LOOP — condition is always true
let i = 0;
while (i < 5) {
    console.log(i);
    // FORGOT i++ → i is always 0 → 0 < 5 is always true → FOREVER
}

// ❌ INFINITE LOOP — wrong update direction
for (let j = 10; j > 0; j++) {
    console.log(j);
    // j starts at 10 and INCREASES → j > 0 is always true
}
How to prevent infinite loops 1. Always make sure your condition will eventually become false.
2. Double-check that your update step (i++, i--) moves the counter toward the exit condition.
3. If your browser freezes, close the tab immediately — the JavaScript engine is stuck in the loop.

10. Common Loop Patterns You Will Use Forever

10.1 — Accumulator Pattern (Summing Values)

const prices = [29.99, 9.99, 49.99, 19.99];
let total = 0;  // The accumulator — starts at 0

for (const price of prices) {
    total += price;  // Add each price to the running total
}

console.log(total);  // 109.96

10.2 — Search Pattern (Finding a Specific Item)

const users = ["Alice", "Bob", "Idris", "Diana"];
let found = null;

for (const user of users) {
    if (user === "Idris") {
        found = user;
        break;  // No need to check the rest
    }
}

console.log(found);  // "Idris"

10.3 — Filter Pattern (Building a New Array From Criteria)

const scores = [45, 82, 93, 31, 76, 88];
const passing = [];  // New array to collect results

for (const score of scores) {
    if (score >= 70) {
        passing.push(score);  // Add passing scores to the new array
    }
}

console.log(passing);  // [82, 93, 76, 88]

10.4 — Transform Pattern (Converting Each Item)

const names = ["alice", "bob", "charlie"];
const capitalized = [];

for (const name of names) {
    capitalized.push(name[0].toUpperCase() + name.slice(1));
}

console.log(capitalized);  // ["Alice", "Bob", "Charlie"]
These patterns are the DNA of programming Accumulate, search, filter, and transform — nearly every algorithm you will ever write is a combination of these four patterns. Once you can recognize them, Codewars problems become much easier to approach.
