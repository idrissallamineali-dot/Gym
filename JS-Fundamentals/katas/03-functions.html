⚙️ Function Katas

20 challenges focused on closures, higher-order functions, callbacks, and functional patterns. These test your deep understanding of how functions work.

01Medium

once(fn)

Create a function that wraps fn so it can only execute once. Further calls return the first result.

const init = once(() => "DB connected!");
init()  // "DB connected!"
init()  // "DB connected!" (cached, fn not re-executed)
Use a closure with a boolean flag and a result cache.

Solution

function once(fn) {
    let called = false, result;
    return function(...args) {
        if (!called) { called = true; result = fn(...args); }
        return result;
    };
}
02Easy

negate(fn)

Takes a predicate function, returns a new function that returns the opposite boolean.

const isOdd = n => n % 2 !== 0;
const isEven = negate(isOdd);
isEven(4)  // true
isEven(3)  // false
Must be a one-liner arrow function.

Solution

const negate = fn => (...args) => !fn(...args);
03Medium

compose(...fns)

Apply functions right-to-left.

const add1 = x => x + 1;
const double = x => x * 2;
const composed = compose(double, add1);
composed(3)  // 8 → add1(3)=4, double(4)=8
Use reduceRight. One expression.

Solution

const compose = (...fns) => val => fns.reduceRight((acc, fn) => fn(acc), val);
04Medium

pipe(...fns)

Apply functions left-to-right (opposite of compose).

const add1 = x => x + 1;
const double = x => x * 2;
const piped = pipe(add1, double);
piped(3)  // 8 → add1(3)=4, double(4)=8
Use reduce. One expression.

Solution

const pipe = (...fns) => val => fns.reduce((acc, fn) => fn(acc), val);
05Medium

partial(fn, ...presetArgs)

Return a new function with some arguments pre-filled.

const add = (a, b, c) => a + b + c;
const add5 = partial(add, 5);
add5(10, 20)  // 35
Use spread operator and closures.

Solution

const partial = (fn, ...presetArgs) =>
    (...laterArgs) => fn(...presetArgs, ...laterArgs);
06Medium

memoize(fn)

Cache results by argument. If called again with same arg, return cached value.

const slow = memoize(n => { console.log("computing"); return n * n; });
slow(5)  // "computing" → 25
slow(5)  // 25 (no log — cached)
Use an object as cache inside a closure. Use the 'in' operator to check cache.

Solution

function memoize(fn) {
    const cache = {};
    return function(arg) {
        if (arg in cache) return cache[arg];
        cache[arg] = fn(arg);
        return cache[arg];
    };
}
07Hard

throttle(fn, limit)

Function can only fire once every limit ms. Calls during the cooldown are ignored.

const log = throttle(() => console.log("fired"), 1000);
log()  // fires
log()  // ignored (within 1000ms)
Use Date.now() and a lastRan variable in a closure.

Solution

function throttle(fn, limit) {
    let lastRan = 0;
    return function(...args) {
        const now = Date.now();
        if (now - lastRan >= limit) {
            lastRan = now;
            return fn(...args);
        }
    };
}
08Hard

debounce(fn, delay)

Function only fires after delay ms of silence. Each call resets the timer.

const search = debounce(q => console.log("Searching:", q), 300);
search("h")    // timer starts
search("he")   // timer resets
search("hel")  // timer resets — only this one fires after 300ms
Use clearTimeout and setTimeout inside a closure.

Solution

function debounce(fn, delay) {
    let timerId;
    return function(...args) {
        clearTimeout(timerId);
        timerId = setTimeout(() => fn(...args), delay);
    };
}
09Hard

curry(fn)

Auto-curry a function of any arity. Allow calling with any number of args at a time.

const add = (a, b, c) => a + b + c;
const curried = curry(add);
curried(1)(2)(3)    // 6
curried(1, 2)(3)    // 6
curried(1)(2, 3)    // 6
Use fn.length, spread, and recursion.

Solution

function curry(fn) {
    return function curried(...args) {
        if (args.length >= fn.length) return fn(...args);
        return (...more) => curried(...args, ...more);
    };
}
10Easy

times(n, fn)

Call fn exactly n times, passing the index (0 to n-1).

times(3, i => console.log(i))  // 0, 1, 2
Use Array.from(). No for loops.

Solution

const times = (n, fn) => Array.from({ length: n }, (_, i) => fn(i));
11Medium

after(n, fn)

Returns a function that only starts executing fn after being called n times. Calls before that return undefined.

const log = after(3, () => "ready!");
log()  // undefined
log()  // undefined
log()  // "ready!"
log()  // "ready!"
Use a counter in a closure.

Solution

function after(n, fn) {
    let count = 0;
    return function(...args) {
        count++;
        if (count >= n) return fn(...args);
    };
}
12Medium

before(n, fn)

Returns a function that only executes fn for the first n calls. After that, returns the last result.

const log = before(3, x => x * 2);
log(1)  // 2
log(2)  // 4
log(3)  // 6
log(4)  // 6 (cached, fn not called)
Use a counter and cache the last result in a closure.

Solution

function before(n, fn) {
    let count = 0, lastResult;
    return function(...args) {
        if (count < n) { count++; lastResult = fn(...args); }
        return lastResult;
    };
}
13Easy

flip(fn)

Returns a function that calls fn with its arguments reversed.

const div = (a, b) => a / b;
const flipped = flip(div);
flipped(2, 10)  // 5  (calls div(10, 2))
Use spread and .reverse().

Solution

const flip = fn => (...args) => fn(...args.reverse());
14Easy

unary(fn)

Wraps fn so it only accepts 1 argument. Extra args are ignored.

["1","2","3"].map(unary(parseInt))  // [1, 2, 3]
// Without unary: ["1","2","3"].map(parseInt) → [1, NaN, NaN]
One-liner arrow function.

Solution

const unary = fn => arg => fn(arg);
15Easy

spreadFn(fn)

Takes a function that expects individual args, returns one that takes an array.

const add = (a, b, c) => a + b + c;
const addArr = spreadFn(add);
addArr([1, 2, 3])  // 6
Use the spread operator. One-liner.

Solution

const spreadFn = fn => arr => fn(...arr);
16Medium

delay(fn, ms)

Returns a function that, when called, executes fn after ms milliseconds. Pass all arguments through.

const greet = delay((name) => console.log("Hi " + name), 1000);
greet("Idris")  // logs "Hi Idris" after 1 second
Use setTimeout and spread operator.

Solution

const delay = (fn, ms) =>
    (...args) => setTimeout(() => fn(...args), ms);
17Hard

promisify(fn)

Convert a Node-style callback function fn(arg, (err, result) => {}) to return a Promise.

const readFile = (path, cb) => cb(null, "file content");
const readAsync = promisify(readFile);
readAsync("test.txt").then(data => console.log(data))
// "file content"
Use new Promise with resolve/reject.

Solution

function promisify(fn) {
    return function(...args) {
        return new Promise((resolve, reject) => {
            fn(...args, (err, result) => {
                if (err) reject(err);
                else resolve(result);
            });
        });
    };
}
18Hard

retry(fn, attempts)

Try calling fn up to attempts times. Return result on success. Throw on final failure.

let tries = 0;
const flaky = () => { tries++; if (tries < 3) throw "fail"; return "ok"; };
retry(flaky, 5)  // "ok" (succeeds on 3rd attempt)
Use a for loop with try/catch.

Solution

function retry(fn, attempts) {
    for (let i = 0; i < attempts; i++) {
        try {
            return fn();
        } catch (err) {
            if (i === attempts - 1) throw err;
        }
    }
}
19Hard

createValidator(rules)

Takes an array of rules {field, test, message}. Returns a function that validates an object and returns error messages.

const validate = createValidator([
    { field: "name", test: v => v.length > 0, message: "Name required" },
    { field: "age", test: v => v >= 18, message: "Must be 18+" },
]);
validate({ name: "", age: 15 })
// ["Name required", "Must be 18+"]
validate({ name: "Idris", age: 25 })
// []
Use filter and map inside the returned function.

Solution

function createValidator(rules) {
    return function(obj) {
        return rules
            .filter(rule => !rule.test(obj[rule.field]))
            .map(rule => rule.message);
    };
}
20Hard

createPipeline()

Returns an object with .add(fn) to add a step and .execute(value) to run the pipeline.

const p = createPipeline();
p.add(x => x + 1);
p.add(x => x * 2);
p.add(x => x - 3);
p.execute(5)  // 9 → (5+1)=6 → (6*2)=12 → (12-3)=9
Use a closure with a mutable array. Execute uses reduce.

Solution

function createPipeline() {
    const steps = [];
    return {
        add(fn) { steps.push(fn); },
        execute(value) {
            return steps.reduce((acc, fn) => fn(acc), value);
        }
    };
}
