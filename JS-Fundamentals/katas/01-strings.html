🔤 String Katas

20 challenges focused on string manipulation. Each kata has a constraint that forces you to solve it a specific way.

01Easy

Reverse a String

Write reverseStr(str) that reverses a string.

reverseStr("hello")   // "olleh"
reverseStr("world")   // "dlrow"
Do NOT use .reverse() or .split(). Use a for loop only.

Solution

function reverseStr(str) {
    let result = "";
    for (let i = str.length - 1; i >= 0; i--) {
        result += str[i];
    }
    return result;
}
02Easy

Count Vowels

Write countVowels(str) that returns the number of vowels (a, e, i, o, u).

countVowels("hello world")   // 3
countVowels("AEIOU")          // 5
Use .match() with a regex. One line.

Solution

const countVowels = str => (str.match(/[aeiou]/gi) || []).length;
03Easy

Write capitalizeFirst(str) that capitalizes only the first letter of a string.

capitalizeFirst("hello")   // "Hello"
capitalizeFirst("javaScript")  // "JavaScript"
Use only slice() and toUpperCase(). One expression.

Solution

const capitalizeFirst = str => str[0].toUpperCase() + str.slice(1);
04Easy

Title Case

Write titleCase(str) that capitalizes the first letter of every word.

titleCase("hello world from js")   // "Hello World From Js"
Use .split(), .map(), and .join() — one chain only. No loops.

Solution

const titleCase = str =>
    str.split(" ")
       .map(w => w[0].toUpperCase() + w.slice(1).toLowerCase())
       .join(" ");
05Easy

Is Palindrome

Write isPalindrome(str). Ignore case and spaces.

isPalindrome("racecar")    // true
isPalindrome("Race Car")   // true
isPalindrome("hello")      // false
Use a for loop comparing characters from both ends. No .reverse().

Solution

function isPalindrome(str) {
    const clean = str.toLowerCase().replace(/\s/g, "");
    for (let i = 0; i < Math.floor(clean.length / 2); i++) {
        if (clean[i] !== clean[clean.length - 1 - i]) return false;
    }
    return true;
}
06Easy

Truncate String

Write truncate(str, max). If string is longer than max, cut it and add "...".

truncate("Hello World", 5)   // "Hello..."
truncate("Hi", 10)            // "Hi"
Use the ternary operator only. One expression, no if/else.

Solution

const truncate = (str, max) =>
    str.length > max ? str.slice(0, max) + "..." : str;
07Easy

Count Words

Write countWords(str). Must handle multiple spaces between words.

countWords("hello world")        // 2
countWords("  hello   world  ")  // 2
countWords("")                    // 0
Use .trim() and .split() with a regex for whitespace.

Solution

function countWords(str) {
    const trimmed = str.trim();
    if (trimmed === "") return 0;
    return trimmed.split(/\s+/).length;
}

09Medium

Longest Word

Write longestWord(str) that returns the longest word in a sentence.

longestWord("The quick brown fox jumped")   // "jumped"
Use .reduce() only. No sort, no loops.

Solution

const longestWord = str =>
    str.split(" ").reduce((longest, word) =>
        word.length > longest.length ? word : longest, "");
10Easy

Repeat String

Write repeatStr(str, n) that repeats a string n times.

repeatStr("ha", 3)   // "hahaha"
repeatStr("ab", 0)   // ""
Do NOT use .repeat(). Use a while loop.

Solution

function repeatStr(str, n) {
    let result = "";
    let i = 0;
    while (i < n) {
        result += str;
        i++;
    }
    return result;
}

kebabToCamel("background-color")   // "backgroundColor"
kebabToCamel("border-top-width")   // "borderTopWidth"

13Medium

Compress String (Run-Length Encoding)

Write compress(str). Consecutive identical characters are replaced by the character + count.

compress("aaabbc")      // "a3b2c1"
compress("aabbbcccc")   // "a2b3c4"
Use a for loop and the accumulator pattern. No regex.

Solution

function compress(str) {
    let result = "";
    let count = 1;

    for (let i = 0; i < str.length; i++) {
        if (str[i] === str[i + 1]) {
            count++;
        } else {
            result += str[i] + count;
            count = 1;
        }
    }
    return result;
}
14Medium

Is Anagram

Write isAnagram(a, b). Ignore case and spaces.

isAnagram("listen", "silent")   // true
isAnagram("hello", "world")     // false
isAnagram("Astronomer", "Moon starer")  // true
Sort the characters and compare. Use .split().sort().join().

Solution

function isAnagram(a, b) {
    const clean = str => str.toLowerCase().replace(/\s/g, "").split("").sort().join("");
    return clean(a) === clean(b);
}
15Hard

Caesar Cipher

Write caesarCipher(str, shift). Shift each letter by shift positions. Wrap around z→a. Preserve case. Non-letters unchanged.

caesarCipher("abc", 3)       // "def"
caesarCipher("xyz", 3)       // "abc"
caesarCipher("Hello!", 5)    // "Mjqqt!"
Use .charCodeAt() and String.fromCharCode(). Handle upper/lower case separately.

Solution

function caesarCipher(str, shift) {
    return [...str].map(char => {
        if (char >= "a" && char <= "z") {
            return String.fromCharCode(((char.charCodeAt(0) - 97 + shift) % 26 + 26) % 26 + 97);
        }
        if (char >= "A" && char <= "Z") {
            return String.fromCharCode(((char.charCodeAt(0) - 65 + shift) % 26 + 26) % 26 + 65);
        }
        return char;
    }).join("");
}
16Medium

Count Substring Occurrences

Write countSub(str, sub). Count overlapping occurrences too.

countSub("banana", "ana")   // 2
countSub("aaa", "aa")       // 2
Use a while loop with .indexOf() and a moving start position.

Solution

function countSub(str, sub) {
    let count = 0;
    let pos = 0;
    while ((pos = str.indexOf(sub, pos)) !== -1) {
        count++;
        pos++;  // move by 1 to catch overlapping
    }
    return count;
}

20Hard

String Permutations

Write permutations(str). Return all unique permutations of a string as an array.

permutations("ab")    // ["ab", "ba"]
permutations("abc")   // ["abc","acb","bac","bca","cab","cba"]
permutations("aab")   // ["aab","aba","baa"]  (unique only)
Use recursion. No libraries. Use a Set for uniqueness.

Solution

function permutations(str) {
    if (str.length <= 1) return [str];

    const result = new Set();
    for (let i = 0; i < str.length; i++) {
        const char = str[i];
        const remaining = str.slice(0, i) + str.slice(i + 1);
        for (const perm of permutations(remaining)) {
            result.add(char + perm);
        }
    }
    return [...result];
}
